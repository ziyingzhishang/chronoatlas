# 亚洲地貌地图交互验证

## 已交付

正式页面 `http://127.0.0.1:5173/`。默认亚洲地形晕渲，可切换卫星影像。支持平移、连续缩放、方位旋转、俯仰、亚洲/中原/全球预设、正北复位；沿用历史时间轴和信息面板。

## 自动检查

- `npm test -- --run`：11 个测试文件，30 项通过。
- `npm run build`：通过 TypeScript 检查与 Vite 生产构建。地图引擎使主脚本约 1.29 MB、gzip 约 369 KB，构建保留大包提示。
- 新测试覆盖年份 GeoJSON、标签落点、无坐标事件、底图图层顺序、保持同一地图实例、初始化期间年份改变、瓦片重试、相机控制与 WebGL 上下文重建。

## 浏览器实际检查

- 两种真实底图可加载，中文标签可读。
- 中原预设缩放到 4.3；旋转按钮改变为 30°；倾斜按钮改变为 45°。
- 切换卫星/地形时，缩放 4.3、方位 30°、俯仰 45°保持不变。
- 切换到 959 年，政权变为后周/契丹，相机保持不变。
- 正北按钮恢复方位和俯仰为 0°。
- Shift＋左方向键旋转到 −15°；Shift＋等号键放大；双击缩放由 2.8 变为 3.8。
- 鼠标实际拖动地图可平移；点击疆域显示对应政权详情。
- 地点目录选择长安，可定位并显示西安市、陕西省与 108.94°E / 34.34°N。
- 全球预设显示全球地形，亚洲复位恢复初始视角。
- 触屏捏合、旋转与俯仰使用 MapLibre 原生手势处理，未在实体触屏设备上测试。

## 复核与限制

独立审查代理因额度限制未运行，已由主代理自行复核，并针对地图重新初始化时过早更新 source 的问题修复、补测。审查未报告为独立审查通过。

底图为现代地形/影像，需要联网；历史疆域仍是现有示意几何，未在本次任务中重新考证。俯仰不表示加入高程网格驱动的三维山体。网络失败提供重试与本地陆地/历史层；WebGL 无法初始化时提供错误说明与重试。

依赖检查：新增 MapLibre 已升级至修复已知漏洞的 6.14.0。既有 Vitest 3.x 开发依赖链仍有 3 条 npm audit 告警（Vitest、@vitest/mocker、tinypool）；未强制升级与本次地图功能无关的测试框架。它们不打包进发布页面。
