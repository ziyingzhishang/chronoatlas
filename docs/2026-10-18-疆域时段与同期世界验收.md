# 疆域时段与同期世界验收

日期：2026-10-18。预览：http://127.0.0.1:5173/ 。本记录说明工程验收，不宣称已完成全部历史疆界的学术校勘。

## 本轮结果

- 中国历史及周边目录87项，85项有Cliopatria时段几何，共625条记录；夏代、更始政权保持缺口。
- 世界11,402条记录、1,458个来源实体，按55个世纪片加载；不是1,458个已核验独立国家。
- 逐年匹配来源区间；缺年时取同政权最大已收录单条记录，用浅色、虚线、来源年代说明，并可隐藏。
- 三国、十六国缺失目录、五代十国、宋辽金夏、明清与近现代均新增来源时段；世界开启后随同一年份变化。
- 原始几何未修改。逐一比较625条中国记录及13,358条世界分片内记录（含跨片重复）与原始GeoJSON，全部一致。所有可选区间端点均非0年，6条原始0边界仍保留供追溯。

## 自动化与独立复核

`npm test -- --run`：15个文件、66项通过。`npm run build`通过，产出独立地图worker资源。

覆盖：完整时间轴无0年、三国分立、两晋、武周、后金/清交接、十六国补缺、西秦中断、最大参考开关、时段变化、世界响应过期/失败重试/取消/共享请求、跨日期变更线定位、地图生命周期及worker失败重试。

独立只读审查发现6项P2并修复；有界二次复核未发现新的P1/P2：

1. 暂隔离跨922—925年的Former Jin别名，写入排除清单，防止和后唐重复。
2. 分开统计中国及周边目录与同期世界，不以中国数量冒充全部图形。
3. 最大参考选中后仍是虚线，不被实线高亮盖住。
4. 隐藏参考的过滤结果缓存，平移/搜索不重复提交历史GeoJSON。
5. 完成缓存与在途请求分离；无消费者取消请求，防慢网拖轴累积下载。
6. 定位考虑经度环绕，允许跨日期变更线显示。

浏览器另发现MapLibre 6.14.0的默认worker相对路径在Vite预打包后失效：底图能显示，但矢量无色块。现通过Vite资源URL显式打包并配置匹配worker；失败时显示可重试错误。此修复另增2项测试，并以实际地图截图验证。

## 诚实保留的限制

没有逐年逐界独立考证；某些来源多年沿用同一几何，最大已收录面积不代表真实历史极大值。源数据里的错名、控制关系与早期断代仍需继续核查。夏代、更始与目录外政权、更多古地名仍待补充。

构建有大包提示：首屏JS约9.36MB（gzip约1.45MB），世界最大世纪片约19.9MB。本地交互已验收，但尚未做低速移动网络性能验收。未隐瞒或关闭构建提示。
