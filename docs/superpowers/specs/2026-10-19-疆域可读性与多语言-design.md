# 疆域可读性与多语言设计

日期：2026-10-19

状态：用户已确认并完成实施；自动化与真实浏览器验收记录见 `docs/2026-10-19-多语言与卫星配色验收.md`。

## 1. 范围与决策

本轮改善现有独立网页应用的地图可读性和阅读语言一致性，不变更历史疆域数据、年份匹配规则或来源许可，不执行公开部署。

采用随底图自动适配的疆域样式，而非要求读者手动调透明度。采用全阅读流程本地化，而非仅翻译按钮。两项分别实现和验收，最终合并验证。

## 2. 卫星影像下的疆域

当前普通疆域填充透明度按可信度为0.40／0.28／0.22，最大参考为0.08，两种底图共用；卫星模式仅调整文字及选中边界颜色。这使覆盖层易被影像纹理淹没。

将呈现参数从历史数据中分离，由底图类型和资料状态共同决定。卫星模式提高普通疆域填充的饱和度、不透明度和边界对比度；同一政权在两种底图保持同一色系。地形模式保留当前整体观感。

初始调色目标：卫星模式普通疆域填充0.50／0.42／0.34，最大参考0.14；允许在真实截图验收时微调，但必须保持最大参考弱于普通疆域，并保留可信度相对层次。边界适当加粗，选中边界保持突出；不能仅依赖填充颜色区分资料状态。

最大参考、间接控制、争议及影响范围保留各自的虚线语义；如添加辅助描边，其过滤条件和虚线必须与对应边界一致，不能把不确定边界画成确定实线。新增描边必须随疆域图层一同开关。图例与实际样式一致，来源与不确定性说明不变。

验收覆盖亮色荒漠、深色森林、沿海及相邻政权；远景和放大后均可辨认，地貌纹理仍能阅读。切换底图、年份和选中对象后样式正确，无需重建地图或重置镜头。

## 3. 语言选项与交互

“更多”中新增语言设置，不增加常驻工具栏按钮：

| 标识 | 原生显示名称 |
| --- | --- |
| zh-CN | 简体中文（中国大陆） |
| zh-HK | 繁體中文（香港） |
| zh-TW | 繁體中文（台灣） |
| en | English |

默认简体中文，保存读者显式选择；存储不可用或值非法时回退简体中文，不影响使用。同步更新文档语言属性、页面标题、辅助技术标签、日期与比例尺单位文字。

切换只改变呈现，不改变年份、底图、镜头、图层、选中对象、时间轴范围和控制器密度。分类与地域筛选使用稳定键值，不随翻译失效。搜索保留读者输入，可匹配本地化名称、原名与已收录别名。

## 4. 翻译覆盖与边界

覆盖界面按钮、提示、错误与加载状态、图例、时间轴、朝代政权、古今地名、事件标题和正文、资料说明、详情面板及可访问性文字。公元前后日期遵循各语言表述且继续跳过公元0年。

香港、台湾版本分别维护地区术语及专名覆盖，不把机械繁简转换等同于地区本地化。可复用共同繁体文本，但地区差异需有明确覆盖表；历史专名不得通过现代国家名称简单替换。

英文版本翻译本地维护的说明和26条事件正文，采用有依据的历史名称，不翻译成未经核实的现代地名。翻译不改变原资料的核验等级、日期精度和不确定性。

同期世界政权按稳定ID维护本地化名称与核验信息。未核实中文译名时保留原名，详情中以当前语言说明“中文译名待核验”；不能用机器生成的音译冒充已核实译名，也不能为了语言一致而隐藏这些政权。交付记录列出已覆盖和回退数量，不声称世界实体全部完成翻译。

来源机构、作者、许可证名称及原文献标题保留必要原文；来源说明翻译，链接与署名不删除。若底图像素中存在文字，不伪称能够随界面即时翻译，不遮盖必要版权信息。

## 5. 实现边界与数据流

建立单一语言状态及类型约束的界面词典。历史实体与事件通过稳定ID关联翻译资源；原始史料、几何和实体ID不变，不为每种语言复制疆域文件。

独立的本地化解析函数负责界面文案、历史名称、日期与回退状态。组件共享这些函数；地图数据生成接收语言参数，更新文字属性而非创建新地图实例。语言变化即使年份未变，也必须刷新地图标签和侧栏。

地区覆盖、原名回退和翻译完整性在开发期可检查。缺失界面翻译属于验收失败；历史世界名称的明确原名回退属于允许状态。运行时仍需安全回退，不能显示内部键名或空标签。

不接入运行时在线翻译服务，不新增账号、后台或网络传输用户输入。语言资源的加载策略在实施计划中依据实际体量确定，不显著复制现有大体积地图数据。

## 6. 验收与回归

- 配色测试：两种底图对应不同呈现参数；普通／最大参考／争议／选中状态、图层开关及年份更新均正确。
- 语言测试：四套界面词典完整、地区覆盖有效、无原始键泄漏；原名回退有明确标识，已核验译名正常显示。
- 联动测试：切换语言保持地图实例、视角、年份和选择；事件正文、地图名称、时间轴和比例尺同步更新；跨公元日期正确。
- 搜索测试：本地化名称与原名都可查，切换语言不破坏筛选。
- 布局测试：桌面、手机及矮屏检查英文长文本和繁体文字，无控件遮挡、页面溢出或署名消失。
- 运行全量测试与生产构建，真实浏览器保存两种底图与四种语言的代表截图，独立代码审查后修复重要问题。

本地验收不等于真实手机弱网性能或公开发布合规验收；这些沿用现有待办。
