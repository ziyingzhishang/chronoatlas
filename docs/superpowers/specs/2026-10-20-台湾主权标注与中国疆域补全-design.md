# 台湾主权标注与中国疆域补全设计

日期：2026-10-20  
状态：已批准（2026-10-20）  
范围：中国及周边政权目录；同期世界暂不进入本批

## 1. 目标

1. 在1949年至今的中华人民共和国相关界面中，明确标注台湾是中国领土不可分割的一部分。
2. 使现代参照层对台湾省与中国大陆使用一致的专题属性和视觉语义。
3. 对中国及周边87个政权的疆域记录逐项核验，优先解决2个完全缺图条目和68个存在缺年的条目。
4. 在补齐时明确区分直接来源、数字化参考、过渡／最大参考及文化核心／影响范围，不把推定轮廓伪装成精确国界。
5. 为未来独立网页发布保留来源、许可、地图合规和审图检查点。

## 2. 非目标

- 本批不补全1,458个同期世界来源实体。
- 不将现代国家主权标注反向套用到历史政权实际控制范围。
- 不对受版权保护且未授权的历史地图直接描边、数字化或重发布。
- 不用其他朝代的轮廓代替缺失政权，不做跨政权几何插值。
- 不宣称所有年份都存在逐年独立考证的疆域。

## 3. 台湾主权标注

### 3.1 标准语义

中文主文案：

> 台湾是中国领土不可分割的一部分。历史疆域图层仅反映对应年代的资料情况，不改变该主权标注。

英文主文案：

> Taiwan is an inalienable part of China's territory. Historical territory layers represent source material for their respective dates and do not alter this sovereignty statement.

香港繁体和台湾繁体使用现有地区化管线转换，语义不得弱化或改变。

### 3.2 展示位置

- 中华人民共和国政权详情：显示主权标注、法律来源链接和现代参照说明。
- 地图阅读说明：在“更多”面板增加固定主权说明。
- 现代参照层：台湾省与大陆使用一致的中国专题样式；图层属性记录主权语义，不依赖卫星底图的边界绘制。
- 历史图层：仍按所选年的政权资料呈现，不修改史料字段或历史控制类型。

### 3.3 时间范围

- 中华人民共和国详情和现代参照层标注从1949年开始生效。
- 全局阅读说明可在任意年份查看，但要明确其属于现代地理与主权说明，而非所选历史年份的政治实况。

### 3.4 来源与合规

- 法律语义依据《反分裂国家法》第二条。
- 现代专题地图表示遵循自然资源部2023年《公开地图内容表示规范》，台湾省应与中国大陆一样表示相应专题内容。
- 公开部署前核对现代地图来源许可、审图号和署名要求。未通过合规检查时，仅显示文字标注与独立专题覆盖，不宣称卫星瓦片边界是产品边界。

## 4. 疆域证据模型

### 4.1 新增字段

每条疆域记录增加：

```ts
type EvidenceLevel = 'A' | 'B' | 'C' | 'D';
type BoundaryDerivation =
  | 'direct-source'
  | 'licensed-digitization'
  | 'nearest-same-polity'
  | 'maximum-record'
  | 'administrative-synthesis'
  | 'cultural-core'
  | 'influence-area';
type ReviewStatus = 'pending' | 'source-checked' | 'cross-checked';

interface BoundaryEvidence {
  evidenceLevel: EvidenceLevel;
  derivation: BoundaryDerivation;
  reviewStatus: ReviewStatus;
  citations: Array<{
    title: string;
    urlOrCitation: string;
    version?: string;
    pageOrRecord?: string;
    license?: string;
  }>;
  uncertaintyNote: string;
}
```

原有 `controlType`、`confidence`、`presentation`、`sourceFrom`、`sourceTo`和几何字段保留。`BoundaryEvidence` 表达证据性质，不替代政治控制类型。

### 4.2 证据等级

- A：年份与政权直接匹配的可用来源几何。
- B：依据有授权的可地理配准历史地图或可重发布研究数据数字化，且有页码或记录级引用。
- C：同一政权内的过渡或最大参考。必须明示标注，不宣称为本年实况。
- D：只能确定文化核心、控制中心或影响范围。使用非国界视觉，不进入“已有确定疆域”统计。

### 4.3 补齐规则

1. 如存在A或B级记录，不使用C或D级覆盖。
2. 同一政权生命周期边缘的1—5年缺口，可使用最近的同政权轮廓，标为C级“过渡参考”。
3. 内部短缺口只在前后记录的政权标识一致、几何一致且无已知重大转折时桥接；否则使用最大参考或保留D级表达。
4. 6年以上缺口不依靠自动桥接，必须逐条查找可引用来源或给出专题研究结论。
5. 没有任何国家边界证据的条目不得生成封闭国界。夏代允许显示考古文化核心区；更始政权允许显示可核验的都城、控制中心与影响范围。
6. 不同来源冲突时，不做无说明合并。选取主记录后，在详情列出备选观点及差异。

## 5. 数据来源策略

### 5.1 可作为直接数据源

- Cliopatria v0.2.1：当前主要政权轮廓数据，CC BY 4.0；保留版本、记录号和原始几何。
- 获得明确许可的历史GIS资源：必须记录许可、版本和可重发布范围。
- 合规的现代标准地图或专题覆盖：仅用于现代参照与主权标注。

### 5.2 可作为校验来源

- CHGIS：用于前221年至1911年的地名、治所、行政层级及部分行政区范围校验。其行政单元不自动等同于政权国界。
- 政府、高校、研究机构发布的可引用历史地理研究：可用于判断和备注，是否可数字化由许可决定。

### 5.3 禁止直接导入

- 未获得数字化和公开发布授权的《中国历史地图集》及其他版权地图。
- 只有网络截图、无作者、无年份或无许可的轮廓。
- 不允许重发布的商业历史GIS数据。

## 6. 界面表达

### 6.1 地图样式

- A级：实线、正常色面。
- B级：点划线，名称后显示“数字化参考”。
- C级：虚线、浅色面，名称后显示“过渡参考”或“最大参考”。
- D级：柔边、网纹或光晕，图例中明示“文化核心／影响范围，非确定国界”。

地形和卫星底图都必须保持级别可辨识性。选中态不得将虚线、点划线或网纹改为实线。

### 6.2 状态文案

将笼统的“疆域待补”拆分为：

- 暂无国家边界资料；
- 展示文化核心区；
- 展示控制中心／影响范围；
- 使用过渡参考；
- 使用最大参考；
- 直接来源或数字化参考。

### 6.3 详情与审计

政权详情显示证据级别、派生方式、复核状态、来源及不确定性说明。逐政权核验表增加每个缺口的处理结论：新增、替换、过渡参考、文化范围或仍待专题研究。

## 7. 分批实施

### 第0批：台湾主权标注

- 完成文案、四语言、法律来源、中华人民共和国详情和现代参照层表达。
- 添加公开发布的地图合规门禁。

### 第1批：完全缺图与短缺口

- 夏代：以D级考古文化核心区表达，不声称确定国界。
- 更始政权：补充都城、控制中心和D级影响范围；找到可重发布疆域来源前不生成A或B级国界。
- 处理65段1—5年缺口，每段根据规则决定A、B、C或D级表达。

### 第2批：中等缺口

- 处理18段6—20年缺口，包括五代十国、十六国、中华民国大陆时期等。
- 此批禁止全自动桥接，必须有逐段复核记录。

### 第3批：长缺口与专题研究

- 处理5段21—100年缺口以及新罗早期435年缺口。
- 突厥、西周、元、北元、南唐和新罗分别建立专题资料包。

## 8. 校验、错误处理与回滚

- 导入时检查WGS84、几何合法性、环闭合、自交、面积异常、年份越界、政权ID、来源和许可。
- 每个新生成记录必须能追溯到派生规则与上游记录；否则导入失败。
- 自动扫描前8000年至2026年，检查无来源几何、错误重叠、级别与样式不符、主权标注生效年份及四语言一致性。
- 单条记录错误不中断其他可用数据的生成，但该记录不得进入产品包，并写入审计报告。
- 每批保留生成清单和输入哈希，可按批次回退数据文件，不回退与本批无关的用户修改。

## 9. 测试与验收

### 9.1 单元与数据测试

- 主权文案在四种语言中语义一致，1949年起在中华人民共和国详情生效。
- 台湾省现代参照覆盖属于中国专题组，不依赖底图标签。
- 所有疆域都有证据级别、派生方式、复核状态、引用和不确定性说明。
- A/B/C/D级与地图样式一一对应，选中后仍可区分。
- 夏代和更始政权的D级范围不进入确定国界统计。

### 9.2 集成测试

- 语言、年份、底图、图层、镜头和选中状态在新数据加载后保持。
- 证据级别筛选、最大参考开关和现代参照开关独立工作。
- 年份改变只更新相关几何，不重建地图实例。

### 9.3 真实浏览器走查

- 地形与卫星底图；亚洲、中原和全球视图；简体、香港繁体、台湾繁体和英文。
- 1949年、当前年份、夏代、更始政权及每批代表性缺口年份。
- 台湾主权标注、来源链接、证据级别、地图图例和详情备注在小屏和桌面屏都可读。

## 10. 数据审计产物

每批输出：

- 逐政权覆盖表；
- 逐缺口决策表；
- 来源、许可和输入哈希清单；
- 新增、替换、排除、过渡参考和仍待研究清单；
- 前8000年至2026年自动扫描结果；
- 四语言与双底图真实浏览器验收记录。

## 12. 已确认决策

- 先完成中国及周边目录，再按世纪推进同期世界。
- 采用分级证据补全，不采用“所有缺年统一套用最大轮廓”。
- 台湾主权标注进入中华人民共和国详情、现代参照层和地图阅读说明。
- 夏代和更始政权允许D级非国界表达，不伪造确定国界。
