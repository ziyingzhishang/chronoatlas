# 响应式历史地图工作台设计

日期：2026-10-18

状态：用户已批准实施；2026-10-19 完成本地实现与验收。独立网页应用目标不变，本轮未公开部署。验收见 `docs/2026-10-19-工作台与事件验收.md`。

## 1. 目标与范围

将现有长页面改为地图工作台：调整年份时地图始终可见；桌面时间控制器支持底部平铺与悬浮，手机使用底部抽屉。保留现有地形／卫星切换、缩放旋转俯仰、同期世界、历史目录、资料状态和来源说明。

本轮仅修改当前 React 网页交互，不新增历史疆域、不改变历史推断规则、不新增账号系统、收藏或分享后台。发布目标为独立网页应用，替代上一版微信小程序目标；不再安排微信专属适配。公开部署需要另行确认域名、托管、授权及审核条件，本轮不执行发布。

历史转折事件作为紧接布局之后的独立子项目，见同目录 `2026-10-18-历史转折事件-design.md`。工作台先提供简洁事件入口和可复用详情容器，事件内容与交互单独验收，不能只改界面而遗漏内容细化。

## 3. 自适应布局

### 3.1 视觉优先级

地图是主内容，控制器是辅助。首屏不显示大标题、宣传说明、长目录、多个展开面板或大面积装饰；保留短产品名，不另加装饰性水印。

常驻内容限于时间控制器、简洁地图导航、资料状态与必要署名，以及“图层”“事件”“详情／更多”三个带文字的分组入口。底图、同期世界和最大参考归入图层；帮助、来源和免责声明归入更多。基础缩放与复位直接可用，旋转俯仰保留手势及可展开按钮。

主要动作使用简短文字或图标加文字，不靠用户猜测无标签图标。默认右侧详情关闭，选择地域／政权／事件后才展开；同一时刻只打开一个辅助内容面板，避免图层、事件和详情互相遮挡。时间控制器独立保留。

背景采用克制、足够不透明的面板保证文字对比度；不以降低文字透明度、缩小点击面积或隐藏必要数据状态换取干净。默认不在地图上铺满事件标签。

### 3.2 宽高适配

断点为首轮实现参数，按 CSS 像素和实际可用视窗判断，而非设备名称。网页采用动态视窗高度与安全区内边距；不以隐藏溢出裁掉必要内容。

| 条件 | 布局 | 时间控制器 |
| --- | --- | --- |
| 宽度至少 1100 且高度至少 700 | 短顶栏、地图、右侧按需打开详情栏 | 默认底部停靠；可切换悬浮 |
| 宽度至少 768，未满足上一行 | 精简顶栏；详情按需侧向展开，面板内部滚动 | 默认紧凑停靠；允许悬浮，限制在可见区域 |
| 宽度小于 768 | 单地图视窗；详情使用可关闭面板 | 底部三档抽屉，不允许自由拖动 |
| 任意宽度但高度小于 500 | 优先地图；工具和详情按需展开 | 紧凑横向控制，扩展内容独立滚动 |

地图主区域不能随说明、目录或详情增长而被推出视窗。帮助、图例、免责声明、数据源和世界目录进入带标题的可展开面板；信息不删除。地图容器改变尺寸后调用已有 resize 逻辑，不能通过重建地图实现布局切换。

放大系统字体或浏览器缩放时，允许控件换行及面板内滚动；极小视窗仍可访问所有功能，不强行保证固定像素地图高度。

## 4. 时间控制器

### 4.1 三种信息密度

- 收起：年份、时期简述、上一年、下一年、展开入口；仍可调年并看到地图。
- 紧凑（默认）：年份、时期、逐年按钮、播放／暂停、带年份刻度的滑条、展开入口。复杂并立时期用摘要表示，完整名称在展开层可读。
- 展开：现有精确年份输入、范围预设、朝代色带、时间轴放大缩小与平移、资料变化节点、历史转折跳转。保留《资治通鉴》快速选择。

展开区域限制高度并内部滚动。手机展开时至多占可用高度约 55%；手柄和切换按钮都可以改变档位，不能仅靠手势。低高度窗口的展开态上限为可用高度约 60%。

### 4.2 停靠与悬浮

桌面／平板提供明确的“悬浮／停靠”按钮。悬浮拖动仅从专用手柄开始，不拦截滑条和地图手势。提供键盘可操作的停靠及归位按钮；手柄获得焦点后可用方向键移动。

控制器靠近可用区域边缘时吸附；拖动、屏幕旋转、调整窗口尺寸及展开时都重新限制坐标，不得移出屏幕或覆盖必要署名。悬浮位置、桌面布局偏好可存本地；存储不可用或内容损坏时回退默认值。进入手机布局强制底部抽屉，但不覆盖桌面偏好；返回桌面时恢复并校正位置。

时间轴已有全历史、朝代、逐年缩放能力继续复用。紧凑刻度在窄屏减少文字密度，不减少按年选择能力。公元前 1 年后为公元 1 年，不引入公元 0 年。

## 5. 地图联动与数据状态

年份仍由 App 统一管理，布局切换不改变年份、底图、镜头、图层或同期世界开关。调年保留当前镜头，不自动缩放到全国；用户主动点击定位或复位除外。

拖动滑条即时更新年份，昂贵的地图更新按浏览器绘制节奏合并，松手后确保显示最终年份。沿用世界资料的过期请求取消机制；加载中的旧资料不能被标为新年份，失败状态有重试入口。

地图始终保留简短资料状态：来源时段匹配数量、最大范围参考数量或暂无资料。详情解释“按年查询不等于逐年考证”。并列存在匹配和最大参考时同时说明，不能只显示一个笼统状态。最大参考隐藏开关继续有效。

## 6. 署名与来源

将产品装饰与来源署名分开。自有装饰可在界面显示设置中关闭；必要来源信息不提供完全隐藏开关。

底图署名保留可读且可点击的显示区域，长说明可展开。具体缩略／折叠形式以实际底图服务条款为边界；未确认可折叠的必要署名继续直接显示，不因已有控件提供折叠选项就推定服务允许隐藏。

历史数据的来源、许可、版本清单与核验表入口继续可达。底部时间控制器、手机安全区、地图导航不得覆盖署名。公开发布前另行复核底图授权与地图审核要求；本轮界面改造不代表取得发布许可。

## 7. 实现职责边界

- `src/app/App.tsx`：统一年份和资料状态，组合工作台，维护抽屉互斥与选择后的详情展示。
- 新工作台布局组件及状态模块：视窗分类、停靠／悬浮、尺寸边界、偏好恢复；不处理历史数据。
- `src/components/Timeline.tsx`：复用现有时间选择行为，支持信息密度；不复制另一套年份状态。
- `src/components/MapView.tsx`：拆分画布常驻控件与可展开目录、说明；镜头与底图状态保留。
- `src/components/HistoricalMapCanvas.tsx`：保留地图实例生命周期及 resize，按实际需要调整署名容器。
- `src/components/InfoPanel.tsx`：保持详情内容，交由工作台决定停靠或抽屉展示。
- `src/styles/theme.css` 及必要的独立工作台样式：视窗级布局、宽高断点、安全区、触控尺寸。

不为本轮引入新 UI 框架。若组件过长，仅按本轮布局职责拆分，避免无关重构。事件入口与详情容器为后续事件子项目复用，不另建常驻事件栏。

## 8. 可访问性与错误处理

主要触控按钮目标尺寸约 44×44 CSS 像素。窄朝代色带保留，同时提供可访问的朝代下拉作为等效入口。抽屉按钮具备名称、展开状态和关联目标；关闭后焦点回到触发控件。遮罩式详情支持 Escape 关闭和焦点管理，非模态时间控制器不困住焦点。

地图、时间轴和窗口拖动手势分区；仅手柄禁用浏览器默认拖动手势，面板正文允许滚动。降低动态效果偏好时关闭非必要过渡。

世界数据加载失败、WebGL 失败和本地存储失败不互相影响；继续提供现有错误说明及重试，不让空白面板阻断年份操作。

## 9. 验收

自动化测试覆盖：布局分类、矮屏优先规则、悬浮边界、偏好回退、密度切换不重置年份、年份跨公元边界、隐藏详情可再打开、署名仍可达。先运行失败测试，再添加实现。

真实浏览器检查：1440×900、1366×768、1024×600、390×844、844×390；另检查浏览器缩放及动态调整窗口。

每组验证：年份控制与地图同屏；地图可缩放旋转；平铺／悬浮切换和窗口缩小时控制器不丢失；手机三档可通过按钮操作；详情与长目录可滚动；切换布局后地图镜头和年份保持；署名未遮挡；世界开启后的加载与失败提示可见。

运行完整测试和生产构建，并独立代码审查。既有大数据包警告单独记录，不将本轮宣称为移动端性能优化完成。

## 10. 独立网页应用后续阶段

发布形态为独立域名下可直接访问的网页应用，兼容桌面和移动浏览器，首版无需登录。继续使用现有 React／MapLibre 技术栈，不引入微信主体、web-view 或原生小程序路线。

工作台和事件体验验收后，另行处理按需加载、不同缩放精度、缓存与数据版本、部署路径及 HTTPS；检查桌面浏览器和 iOS／Android 真机上的多边形精度、地形／影像、旋转缩放、内存、网络错误及页面前后台切换。正式托管前需要用户确定域名和部署环境。

可安装到桌面的 PWA 能力作为可选后续增强，并非独立网页发布的前提。不承诺离线地图；离线缓存影像和数据需先确认许可及容量策略。

发布前专项处理：历史内容审校、底图及历史数据许可、地图审核与适用资质、隐私与网络部署条件。这些不由“仅供参考”声明替代。
