# 山河年轮两态时间导航设计

日期：2026-10-26  
状态：已批准的设计规格，待实施计划  
适用仓库：`chronoatlas`

## 1. 背景

当前时间控制器同时包含折叠、紧凑、展开三档密度，又有停靠、悬浮与归位布局状态。紧凑态仍显示年份标题、步进、播放、刻度、滑条与事件聚合点；展开态则同时承担精确输入、范围预设、朝代选择、总览、缩放平移、资料变化与事件目录。用户在移动年份前，需要先理解控制器状态。

本设计将时间交互收敛为：

1. **地图探索操作条**：只负责移动时间。
2. **时间分析面板**：负责在历史结构中定位。

本规格替代 2026-10-26 上一版设计中关于“折叠/紧凑/展开三档密度”和“紧凑态常驻事件点”的部分；年份、地图镜头、时间视窗、阅读状态与导航历史的独立性保持不变。

## 2. 设计目标

- 用户在地图上一眼看到如何逐年移动、播放与打开时间轴。
- 常驻操作条高度不超过 52px 加安全区，尽可能保留地图面积。
- 将时间移动、历史结构定位、事件解释和研究工具分层。
- 在桌面、真实分栏后的窄地图栏、平板、手机竖屏与手机横屏上都有明确形态。
- 折叠或关闭时间分析不改变年份、时间视窗、地图镜头、图层或专题状态。
- 继续保证前1年与公元1年直接相邻，不产生公元0年。

## 3. 信息层级

1. **顶部历史状态卡**：说明当前正在阅读什么。显示年份、代表朝代、语义视窗、距今与视窗范围。
2. **底部操作条**：说明怎样移动时间。显示小型年份/朝代语境、上一年、播放/暂停、下一年、快速拖动与打开时间轴。
3. **时间分析面板**：说明当前年份在历史结构中的位置。显示范围、朝代/政权带、刻度、滑条、精确年份与视窗恢复。
4. **注释层**：说明该时间为何重要。事件与资料变化互斥显示，默认不同时堆叠。
5. **更多时间工具**：收纳全历史/《资治通鉴》预设、缩放平移、资料断面列表、完整事件目录和时间控制器布局选项。

## 4. 地图探索操作条

### 4.1 布局

```text
[前845年 · 西周]  [−1] [播放/暂停] [+1]  ━━━◇━━━  [时间轴 ⌃]
```

优先级：

1. 播放/暂停、上一年、下一年。
2. 打开时间轴。
3. 当前年份与代表朝代。
4. 快速拖动轨道。

宽度不足时，按 4 → 3 的顺序逐步收缩，但播放、步进和时间轴入口不隐藏。若隐藏视觉年份，操作组的可访问名称必须包含当前历史年份。

### 4.2 行为

- `−1` 与 `+1` 按无公元0年的年份索引步进。
- 播放过程中按钮变为“暂停”，地图应跟踪最新年份，不重建地图或改变镜头。
- 快速拖动使用 `input` 预览与 `change` 最终提交协议；拖动中在游标上方显示临时年份。
- 用户手动步进、拖动、输入或选择事件年份时停止播放。
- 只保留一个“打开时间轴”入口，不再并列“刻度”、“展开”和手柄点击三种密度入口。
- 常驻条不显示事件聚合点或资料变化节点。

### 4.3 停靠与悬浮

- 默认停靠在 `MapPane` 底部，与地图共享同一容器宽度。
- 时间条不得进入专题栏区域。
- “悬浮/停靠/归位”从常驻操作移入“更多 → 布局”。
- 悬浮只在 `MapPane` 足够宽、足够高时可用；平板竖屏、手机和矮屏始终停靠。
- 为兼容已有本地偏好，旧悬浮配置可读取，但在不支持的尺寸上不应生效。

## 5. 时间分析面板

### 5.1 桌面与横向平板

```text
[−1] [播放] [+1]   当前视窗：王朝至今  [范围 ⌄] [关闭 ⌄]
────────────────────────────────────
朝代/政权带，最多两个可见层级
年份刻度 ━━━━━━━━━◇━━━━━━━━
[精确年份] [回到当前年份]       注释：[无] [事件] [资料变化]
```

要求：

- 1440×900 与 1024×768 的建议展开高度不超过 220px，不依赖内部滚动完成主任务。
- 删除时间面板中与顶部状态卡重复的大年份标题、巨型朝代标题和第二套播放按钮。
- 范围选择不默认改变当前年份；朝代选择只改变语义视窗。
- 当前年份不在视窗中时显示提示和“回到当前年份”，不自动跳转。
- 朝代带不仅用颜色表达，并提供下拉或列表等价入口。

### 5.2 注释层

注释层为互斥状态：

```ts
type TimelineAnnotationLayer = 'none' | 'events' | 'changes';
```

- 默认为 `none`，保持刻度可读。
- `events` 显示视窗内的事件聚合点。
- `changes` 显示已发布的资料变化节点。
- 未启用的注释不在 DOM 或无障碍树中挂载。
- 选择单一事件可打开事件详情；只有用户明确选择“查看该时期”或选择事件年份时才改变地图年份。
- 完整事件目录不常驻在时间面板；顶部搜索仍是主要事件发现入口。

### 5.3 更多时间工具

以二级弹出层或独立工具页收纳：

- 全历史、王朝至今、《资治通鉴》时间范围。
- 时间轴向前/向后平移、放大、缩小与逐年视窗。
- 完整资料断面列表与完整事件目录。
- 宽屏条件下的悬浮/停靠与归位。

这些工具不与基本步进、播放和滑条并列，不应让新用户在移动一年前理解缩放与断面语义。

## 6. 响应式形态

响应式判断必须以 `MapPane` 的实际容器宽度与高度为准，不仅使用 `window.innerWidth`。

### 6.1 宽地图栏

- 底部操作条显示年份、朝代、步进、播放、快速拖动和时间轴入口。
- 时间分析停靠在地图栏底部，不覆盖或跨入专题栏。

### 6.2 专题分栏后的窄地图栏

- 按实际约 560px 地图栏宽度缩短年份与朝代文字，优先保留三个播放/步进按钮和时间轴入口。
- 快速拖动条可缩短或隐藏，但打开时间轴后必须提供完整滑条。
- 不显示“悬浮”文字按钮或其他宽屏布局操作。

### 6.3 手机竖屏

```text
[−1] [播放] [+1] [时间轴]
```

- 年份与朝代由顶部状态卡或操作组可访问名称承担，可不在底栏重复显示。
- 打开后为不超过约 42dvh 的停靠底部面板。
- 每次仅显示一种注释层。
- 所有触摸目标至少 44×44px，并考虑底部安全区。

### 6.4 手机横屏与矮屏

- 高度不足 500px 时，地图态仅保留单行操作条。
- 用户打开时间轴后进入独占时间分析视图，而不在剩余半高地图上堆放控件。
- 关闭、Escape 或系统返回恢复原年份、时间视窗、地图镜头、图层与专题状态。

## 7. 交互状态机

```text
地图探索 / 操作条
  ├─ 步进或播放 → 更新 currentYear
  ├─ 快速拖动 → previewYear → commit currentYear
  └─ 打开时间轴 → 时间分析

时间分析
  ├─ 选择范围/朝代 → 只改变 timelineWindow
  ├─ 回到当前年份 → 让 timelineWindow 包含 currentYear
  ├─ 选择注释 → none | events | changes
  ├─ 选择事件 → 打开事件组/详情，仅在明确操作后改年
  └─ 关闭/Escape → 地图探索
```

状态分离：

- `currentYear`：地图正在呈现的年份。
- `previewYear`：拖动中的短暂预览年份。
- `timelineWindow`：时间轴当前视窗。
- `semanticViewLabel`：王朝至今、《资治通鉴》或指定朝代。
- `annotationLayer`：当前注释类型。
- `timeNavigationMode`：`bar | analysis`。
- 地图镜头、图层、专题选择和导航历史继续由工作台独立管理。

## 8. 无障碍

- 打开时间轴按钮使用 `aria-expanded` 与 `aria-controls`。
- 关闭时间分析后焦点返回原打开入口。
- 滑条保留可读历史年份 `aria-valuetext`，键盘步进跨过前1年/公元1年时不出现0。
- 播放过程不逐年向屏幕阅读器发布消息；暂停、结束或用户直接操作后再播报最终年份。
- 注释层关闭时不在无障碍树中保留其内容。
- 朝代带提供文字列表或下拉等价入口，不只用颜色和空间位置。
- 独占时间分析视图使用可见关闭按钮、Escape、背景 `inert` 和焦点限定。

## 9. 验收标准

### 结构

- 只有“地图探索操作条”和“时间分析打开”两个主要状态。
- 不再并存“刻度”、“展开”、手柄展开和紧凑/展开三档概念。
- 常驻条高度不超过 52px 加安全区，关闭的时间分析内容不占布局也不在 DOM 中挂载。
- 时间控制器任何形态均不进入专题栏区域。

### 交互

- 步进、播放、拖动和精确输入后，年份、地图疆域与资料状态收敛到同一最终年份。
- 朝代选择只缩放语义视窗，不修改当前地图年份。
- 关闭时间分析不重置年份、视窗、镜头、图层、专题或导航历史。
- 事件与资料变化不同时形成两排常驻节点。
- 前1年与公元1年直接相邻。

### 响应式与视觉回归

必须验证：

- 1440×900
- 1024×768
- 809×934
- 390×844
- 844×390
- 桌面真实分栏后约 560px 的 `MapPane`

检查：

- 页面无横向滚动。
- 时间控制不遮挡比例尺、地图署名或专题栏。
- 常规桌面时间分析打开后仍保留约 70% 地图高度。
- 手机竖屏底部面板不超过约 42dvh。
- 手机横屏与矮屏使用独占时间分析视图。
- 分栏拖动后时间条按 `MapPane` 容器自适应，不根据整个窗口误判为宽屏。

## 10. 决策记录

1. 选择两态时间导航，不保留三档密度作为用户心智模型。
2. 考虑到已批准的折叠条需求，宽屏操作条保留小型年份与朝代；手机可在可访问名称中保留上下文而不重复显示。
3. 将“刻度”和“展开”合并为一个时间轴入口。
4. 将悬浮/停靠/归位降级为宽屏高级布局选项。
5. 将事件与资料变化设为互斥注释层。
6. 不以时间面板取代顶部事件搜索。
7. 不以时间范围选择暗中修改当前地图年份。
