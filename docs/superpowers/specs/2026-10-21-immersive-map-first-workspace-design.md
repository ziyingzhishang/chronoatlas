# ChronoAtlas 地图优先沉浸式工作台设计

## 目标

将 ChronoAtlas 从“固定顶部栏 + 固定底部时间轴 + 覆盖式面板”的网页工作台，调整为“地图优先、控制器按需出现”的沉浸式历史地图应用。借鉴游戏的 HUD、探索和状态返回逻辑，但保持历史研究所需的来源透明、可访问性和操作可预测性。

## 第一阶段范围

### 探索模式（默认）

- 地图占据浏览器主要可视区域，并延伸到顶部和底部背景。
- 顶部仅保留轻量 HUD：项目标识、当前年份/时期、控制中心入口。
- 底部时间控制器默认收缩为约 48—60px 的轻量条，显示播放、当前年份和展开入口。
- 地图、年份和播放是常驻操作；图层、事件、详情和来源通过控制中心或面板召唤。
- 用户停止交互后，展开的临时提示可以收起，但不能隐藏当前年份、返回和关闭入口。

### 分析模式

- 点击完整时间轴、图层、事件或详情后进入分析模式。
- 完整时间轴和侧面/底部面板可以占据可读空间。
- 顶部显示当前分析上下文，并提供“返回探索”入口。
- 关闭面板后恢复探索模式，不改变用户当前年份和地图镜头，除非用户明确选择返回上一步。

### 统一返回模型

应用分别维护四类状态：当前年份、时间轴视窗、地图镜头、面板/选择状态。

- 时间轴下钻保存上一个语义视窗，提供“返回上一级”和“回到当前年份”。
- 地点、政权或事件定位保存上一个地图镜头，提供“返回上个视角”。
- 事件列表和事件详情分层，详情提供“返回事件列表”。
- “全历史”“亚洲复位”继续作为明确的预设动作，不承担返回功能。
- 普通拖动、每一次缩放和每一帧播放不创建返回历史。

## 交互规则

1. 点击朝代或专题色带优先改变时间轴视窗，不隐式改变当前年份；当年份不在视窗内时显示“当前年份不在本视窗内”和明确的跳转按钮。
2. 拖动年份时先更新轻量预览；释放或提交后再更新完整详情、事件和较重的数据层。
3. 事件定位和政权/地点定位使用平滑镜头动画，并提供返回上个视角。
4. 移动端面板使用底部抽屉和遮罩；桌面端使用侧面板或浮动面板。Escape、关闭按钮和遮罩都可以关闭面板，并将焦点返回触发入口。
5. 所有临时浮层必须在键盘、触屏和鼠标下有等价入口，不把关键操作只放在悬停状态。
6. 地图镜头变化采用短时、可中断的动画；尊重 `prefers-reduced-motion`。

## 视觉方向

- 顶部采用半透明 HUD，避免大面积实体色块遮挡地图。
- 地图是第一视觉层，技术状态、来源和详细说明降级到状态条、面板或可展开说明。
- 当前年份使用稳定且高对比的标记；时间轴视窗、事件节点和选中政权使用不同视觉编码。
- 只对用户明确触发的定位、选中和历史变化做轻量动画，不使用持续闪烁或装饰性动效。

## 第二阶段：地图全局与悬浮控制减法

- 移除地图画布内常驻的项目标题和文字导航；品牌名称保留在页面标题、帮助和来源信息中。
- 地图占满全局，缩放、图层快捷入口、定位和返回上个视角合并为一条悬浮地图控制条。
- 图层入口使用轻量浮层，直接提供历史疆域、历史地名、历史事件、现代参照和底图切换；低频资料设置继续放在展开项中。
- 顶部只显示当前年份/时期与当前时间视窗状态胶囊；“图层”“事件”“详情”“更多”等文字入口改为图标、Tooltip 和可访问标签。
- 时间轴默认收缩为底部 HUD，只保留当前年份、前后步进、播放和展开入口；朝代色带、资料节点和完整年份输入进入分析模式。
- 桌面和移动端悬浮控件必须避开地图版权署名、当前选中对象和安全区；不将所有低频能力堆叠到缩放条中。

## 第三阶段：顶部遮挡与视图形态减法

- 顶部不再使用覆盖地图的大面积黑色渐变条；状态 HUD 独立悬浮，保持低对比度和最小占用，不承担背景遮罩功能。
- 地图控制条增加“平铺 / 球形”视图切换。平铺使用默认 Web Mercator，球形使用 MapLibre Globe；切换只改变投影，保留当前中心、缩放、方向、俯仰和图层状态。
- 图层、底图和同期世界统一由地图控制条进入；右上角工作台移除重复的图层入口，仅保留事件、详情和更多。
- 视图形态使用图标、tooltip 和无障碍标签表达，避免新增常驻文字按钮；在球形模式下仍提供缩放、复位、返回视角和视角调整。

## 不在第一阶段实现

- 完整叙事剧本模式和连续章节播放。
- 3D 地形、角色化游戏元素、积分或任务系统。
- 全量 URL 分享状态；但状态结构应为后续 URL/浏览器前进后退保留接口。
- 重新设计历史数据模型和来源校勘逻辑。

## 验收条件

1. 默认打开时地图不再被大面积固定顶部栏和展开时间轴遮挡。
2. 用户可以从时间轴下钻、事件详情和地图定位分别返回上一步。
3. “复位”与“返回上一个视角”行为明确且互不替代。
4. 桌面和移动端都能打开、关闭和返回面板；关闭后焦点回到入口。
5. 当前年份、当前时间轴视窗、地图镜头和面板状态不会被无提示地互相覆盖。
6. 年份拖动、地图定位和面板切换没有明显卡顿，且减少动作不会破坏历史图层同步。
7. 现有地图来源说明、许可证、历史语义提示和键盘操作继续可访问。
8. 顶部无大面积黑色遮挡；右上角无重复图层入口；地图控制条能在平铺与球形之间切换并保持地图状态。
