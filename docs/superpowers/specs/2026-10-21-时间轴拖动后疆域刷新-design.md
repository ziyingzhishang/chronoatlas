# 时间轴拖动后疆域可靠刷新设计

日期：2026-10-21  
状态：已批准（2026-10-21）

## 问题与复现

快速连续拖动年份滑块时，React 中的当前年份、时间轴标题和疆域资料状态会先更新，但地图画布可能继续显示较早年份的图形。开启“同期世界疆域”后更容易出现。

当前实现将中国及周边疆域与同期世界疆域合并成一个 `boundaries` GeoJSON source。每次年份变化还会同时重建并调用 `setData` 更新疆域、地点、政权标签、事件和现代主权参照。`HistoricalMapCanvas` 用 `requestAnimationFrame` 合并 React 更新，但没有表示“地图已经完成应用哪个年份”的版本状态，也没有在拖动结束时强制确认最终年份。大量世界多边形进入 MapLibre worker 的异步解析队列后，画面与 React 年份可能暂时脱节。

## 目标

- 拖动过程中保持年份反馈流畅，并持续显示最新可处理年份。
- 拖动结束后，地图必须收敛到滑块最终年份。
- 中国及周边疆域更新不应被同期世界大数据阻塞。
- 年份切换不得改变缩放、中心、旋转或俯仰视角。
- 世界分块跨世纪异步加载时，旧世纪数据不得重新覆盖新年份。
- 测试能够直接验证“界面所选年份”和“地图已应用年份”一致。

## 数据源与更新架构

### 1. 分离本地疆域与世界疆域

`buildMapData` 输出独立集合：

- `boundaries`：中国及周边目录疆域；
- `worldBoundaries`：同期世界疆域；
- 其余 `places`、`polityLabels`、`events`、`modernSovereignty` 保持独立。

MapLibre 样式增加 `worldBoundaries` source。疆域渲染层按用途复制为本地层和世界层，或通过最小共享构造函数生成两组同样的证据样式。中国图层先提交，世界图层随后提交；两者仍服从同一个“同期世界疆域”可见性设置。

### 2. 最新年份更新协调器

更新协调器接收带修订号的地图快照：

```ts
interface HistoryFrame {
  revision: number;
  year: number;
  state: HistoricalState;
}
```

- 连续 `push` 只保留尚未执行的最新快照。
- 回调执行时记录其修订号和年份。
- 更旧的异步完成结果不能把“已应用年份”倒退。
- 地图初始化或 WebGL 重建后，直接使用 `latest.current.state` 和最新修订号。

MapLibre 的 `setData` 仍负责内部 worker 更新；应用只提交最新待处理快照，不维护会积累的逐年队列。

### 3. 拖动与最终提交

时间轴滑块同时处理：

- `input`：拖动过程中的连续预览，按动画帧合并；
- `change`／指针或键盘提交：再次提交最终值，即使它与最后一次预览值相同。

应用层区分普通年份变更和最终提交，但二者均更新统一的 `currentYear`。最终提交会递增强制刷新令牌，保证地图在浏览器合并相同 React 值时仍能执行一次最终同步。

按钮、事件跳转、年份输入框和播放模式仍走普通年份变更；它们本身是离散操作，不需要额外拖动提交协议。

### 4. 已渲染年份信号

地图容器增加只读属性：

```html
data-year="1271"
data-rendered-year="1271"
```

`data-year` 表示当前界面选择；`data-rendered-year` 仅在对应年份的数据已提交给地图源后更新。两者短暂不一致时可以设置 `aria-busy="true"`，不新增常驻视觉控件；刷新完成后恢复一致。

此信号用于自动化测试和故障诊断，不改变干净的地图界面。

## 状态与竞态处理

- 世界资料未开启：只刷新中国及周边 source，不构建或推送世界集合。
- 世界资料加载中：先显示该年份的中国疆域；世界 source 清空，避免旧世纪残留。
- 世界资料就绪：仅当分块覆盖当前所选年份时加入世界数据。
- 用户在世界请求完成前跨世纪：已有 `useWorldSlice` 世纪键检查继续阻止旧请求生效；地图修订号再阻止旧帧更新已渲染年份。
- MapLibre style 尚未加载：保存最新快照；`style.load` 后只提交最新快照。
- WebGL 上下文丢失：新 map 实例不继承旧 updater；新样式加载后提交最新快照。
- 卸载：取消动画帧并让协调器失效，禁止迟到回调访问已销毁 map。

## 性能边界

- 不在每个拖动事件中同步序列化并提交全部世界多边形。
- 不重复更新内容未变化的 source；更新函数保存每个 source 最近的数据签名或年份/版本键。
- 中国疆域和标签优先于世界疆域提交。
- 本次不引入 Web Worker、自定义二进制瓦片或全量数据格式重构。

## 测试方案

### 单元测试

- 连续推入多个修订，只应用最新快照。
- 最终提交可以在年份值相同的情况下强制执行。
- dispose 后任何挂起回调均不生效。
- 更旧修订不能倒退 `renderedYear`。

### 组件测试

- 快速触发滑块多个 `input`，最后触发 `change`，地图 source 最终只包含最终年份政权。
- `data-year` 与 `data-rendered-year` 最终相同，等待期间 `aria-busy` 为真。
- 开启世界图层时，中国 source 先刷新且不包含世界实体；世界 source 单独刷新。
- 跨世纪慢请求完成后不能覆盖新世纪年份。
- 初始化、重试和 WebGL 重建仍使用最后选择年份。
- 快速拖动不调用 `flyTo`、`easeTo` 或重建 MapLibre 实例。

### 浏览器验收

在开启和关闭同期世界图层两种状态下，分别快速拖动：800 → 1271 → 1644 → 1912。每次松开后检查：

1. 时间轴标题与资料状态年份一致；
2. 地图疆域和政权标签对应最终年份；
3. `data-year` 等于 `data-rendered-year`；
4. 地图视角不发生跳转；
5. 控制台没有 source、worker 或已销毁 map 错误。

## 不在本次范围

- 不修改历史疆域数据本身；
- 不改变证据等级和样式语义；
- 不自动重置地图视角；
- 不处理长期的数据瓦片化与包体拆分；
- 不调整时间轴整体视觉布局。

## 验收标准

- 快速拖动后两秒内，地图稳定显示最终年份；通常应在下一至数个动画帧内完成中国疆域更新。
- 中国及周边疆域不受世界数据加载状态阻塞。
- 所有新增回归测试、现有全量测试和生产构建通过。
- 浏览器验收覆盖开启／关闭世界图层，并保存至少一组修复前后证据截图。
