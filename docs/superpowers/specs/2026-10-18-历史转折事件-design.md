# 历史转折事件细化设计

日期：2026-10-18

状态：用户已批准实施；2026-10-19 完成首批26条事件及交互验收。具体核验范围与缺口见 `docs/2026-10-18-事件资料核验.md`；不声称穷尽历史或逐年疆域已完成。

## 1. 目标与边界

在独立历史地图网页中，说明历史格局“何时、何地、发生什么、为什么重要”。与响应式地图工作台分为两个依次实施、分别验收的子项目，先布局，再事件。

现有 `src/data/events.ts` 的事件数据与 `src/components/Timeline.tsx` 的快捷节点各自维护，详略和来源呈现不同。本子项目统一事件来源，再逐条考证与扩展，不把现有简述直接视作已核实史料。

范围为精选重要转折，不承诺穷尽历史或每年都有事件。首批优先覆盖中国各主要历史时期的政治与空间格局变化，并提供同期世界精选事件；《资治通鉴》仅为专题筛选，不限制总时间范围。史前与早期材料使用适当精度及争议说明，不虚构确切年份。

## 2. 呈现方式与选择

比较三种方式：地图常驻大量标注会遮挡疆域；独立长篇年表会打断调年观察；推荐时间轴少量标记加按需事件详情，并以可搜索列表补足发现能力。

- 默认不展开事件面板，不显示地图事件标签墙。
- 紧凑时间轴显示重要事件的小标记；位置接近时合并为数量标记，点击打开该组列表，不强行叠字。
- 展开时间轴可筛选事件；完整列表不受标记聚合影响，键盘用户同样可以选择事件。
- 事件面板默认列出所选年份发生或持续的事件；无记录时明确写“本年暂无已收录事件”，不解释为没有历史变化。
- 提供“附近事件”，按时间距离展示并标明实际年份；不能混入本年列表造成误读。
- 选择事件后跳到适用年份并打开详情；跨年事件保留当前年（若当前年位于期间内），否则跳到起始年。
- 选事件不强制改变地图镜头；有可靠地点时提供“定位地点”按钮。无可靠位置时仍有文字详情，不随机指定坐标。
- 手机沿用单一辅助抽屉，切换事件和地域详情而非叠加多个面板。

## 3. 事件内容

每条事件包含：稳定 ID、标题、起止年、年代精度（确年／约年／范围）、地域、分类、关联政权、简述、背景、经过、影响、与地图的关系、来源及核验状态。

日期仅精确到已被来源支持的程度；不为充实内容添加未经确认的月日。重要事件可拆为多个有独立依据的阶段节点，通过共同主题 ID 关联，避免将同一事件不同阶段重复列作独立事件。

分类包括：政权建立／更替、统一／分裂、战争／条约、迁都／迁徙、制度／经济文化转折。政治和空间格局相关事件优先；分类仅用于筛选，不假设每类均改变疆域。

详情按以下顺序呈现：

1. 标题、时间、地区与分类。
2. 一两句说明发生了什么及其重要性。
3. 背景、主要过程、直接结果与后续影响，分段折叠阅读。
4. 与疆域或地名变化的关系；不能确定时明确说明。
5. 出处：原始文献卷／篇或权威机构页面及可访问链接；不同解释并存时列出分歧。

摘要为自行撰写，不复制受版权保护来源的长段文字。历史事实与解释性因果分开措辞，不将单一事件描述为复杂历史变化的唯一原因。

## 4. 史料与地图的关系

逐条核对年份、名称、参与者、地点和结论；可追溯的具体出处比笼统书名更优先。当前只有通用来源标识的旧事件须补充依据，未补齐的标为待核验，不能默认为已核验。

史实核验与空间定位核验是两个独立状态。地点只能确定大致范围时显示“约址”，地理争议在详情解释；不因为事件有文字史料就认为其坐标确定。

事件并不自动产生疆域边界。若事件年缺少适用疆域，照常显示事件文字并提示地图资料缺口；最大范围参考不得被描述为事件造成的实际扩张。

“前后对照”首版仅提供跳至事件前后年份的入口，不新增双地图。每次跳转仍显示真实的数据状态，没有可用疆域时不合成过渡图；跨公元边界跳过 0 年。

## 5. 数据与组件职责

- 扩展现有 `HistoricalEvent`，由 `src/data/events.ts` 或按时期拆分的同类数据模块统一提供内容。
- 时间轴快捷节点从统一事件目录派生，不再保留独立硬编码年表。
- 独立查询函数处理时间范围、地域、分类、关键词及附近事件；跨年事件以闭区间匹配，年代精度另行展示。
- 事件详情复用工作台辅助面板和现有 `SelectedEntity` 的 event 类型，事件数据不嵌入地图渲染组件。
- 地点定位只使用已核对且适用于事件的坐标／地点记录；缺失引用不能导致整个页面失败。
- 改年与选中事件使用一致的状态更新路径，避免现有“年份变化清空选择”逻辑把刚选中的事件清掉。

## 6. 实施批次与验收

第一批统一现有事件与快捷节点、逐条补出处，完成列表、详情和地图联动。第二批按历史时期与地域补充精选事件；以来源核验通过为纳入条件，不用数量目标驱动填充。本子项目的完成记录须列出实际新增与修订的事件、来源，以及尚未覆盖的时期，不宣称全历史完备。

先写失败测试，再实现：同年多事件、跨年持续事件、约年显示、无事件状态、分类与地域筛选、相邻标记聚合、选择后保持事件详情、无地点定位、缺少来源标识回退、跨公元边界、事件年无疆域以及最大参考提示。

人工检查来源是否真正支持字段，界面自动化不能代替史料核实。桌面与手机都要验证：标记无密集重叠，关闭详情后地图干净，必要署名未遮挡，键盘可访问所有事件。

## 7. 不包含

不新增事件动画推演、自动推断边界、AI 生成未核验事件、用户投稿后台、账号或互动评论；不执行公开部署。若后续需要穷尽某个时期，另立内容采编计划。
