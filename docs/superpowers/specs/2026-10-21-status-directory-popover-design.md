# 状态入口与政权地点目录浮层设计

## 目标

将左上角“当前历史状态”从静态信息标签升级为目录入口。点击后，在历史事件搜索框下方展开当前年份对应的政权与地点目录，不再打开右侧工作台面板。

## 交互

- 状态入口、事件搜索框和目录浮层共用左上角对齐线。
- 状态入口点击切换目录浮层的展开与收起。
- 搜索框获得焦点时收起目录，避免两个内容浮层同时展开。
- 目录显示当前年份的政权列表和地点列表；点击条目沿用现有地图定位与详情选择逻辑。
- 点击地图空白区域清除目录中的地图选择，但不改变年份。
- 目录内容过长时在浮层内部滚动，不推动地图布局。
- 左、上、组件间距统一为 16px 外边距和 8px 组件间距。

## 实现边界

- 复用现有 `InfoPanel` 的目录数据和本地化文本，不新增历史数据模型。
- 通过 `App` 管理目录的展开状态，与现有 `panel` 右侧工作台状态分离。
- 目录使用紧凑浮层容器，详情仍可在目录区域内展示；不恢复右侧目录抽屉。
- 保留现有“更多”右下 HUD 和地图控制条，不扩大本次范围。

## 验收标准

1. 点击“当前历史状态”后，目录出现在搜索框正下方。
2. 目录与搜索框宽度、左边缘一致，顶部与组件间距一致。
3. 搜索框聚焦后目录收起，搜索功能不受影响。
4. 目录条目可打开现有政权或地点详情并驱动地图定位。
5. 地图空白点击可以关闭目录选择，年份保持不变。
6. 桌面和窄视口下目录不溢出浏览器边缘。
