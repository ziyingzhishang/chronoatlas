# 政权首都与今地名补全设计

## 目标

为 `chronoatlas` 当前数据目录中的全部政权补全可核验的历史首都或政治中心，并在地图中按当前年份标记历史名称与对应的现代地名。

## 设计决策

现有 `Polity.capitalPlaceId` 只能表达一个静态首都，无法覆盖迁都、多都制、临时行在、陪都和游牧政权政治中心。因此新增独立的首都沿革关系表，保留旧字段作为兼容字段，不从首都点推导政权疆域。

每条关系记录包含政权、地点、有效年份、角色、置信度、来源和说明。角色区分正式首都、陪都/副都、临时首都和政治中心；对没有固定城址的政权使用“政治中心”而非强行标注“首都”。

地点继续复用 `Place`，但新增地点时必须同时提供历史名、现代对应地名、行政区、坐标、定位性质、现代映射状态、置信度和来源。古城遗址、现代城市中心和区域近似定位必须明确区分。

## 地图与面板行为

- 当前年份只显示有效的首都关系；同一政权可以同时显示多个有效地点。
- 首都标记使用独立图层和图例，不与普通事件地点合并。
- 标记属性包含政权名、历史首都名、现代地名、角色和有效年份。
- 选中首都时，信息面板显示历史名、今地名、政权归属、角色、核验状态和来源说明。
- 首都点只表达政治中心位置，不改变边界、主权参照或疆域证据。

## 数据核验边界

- 每个目录政权至少有一条首都/政治中心记录；没有确定固定都城的政权必须显式标注为不确定或政治中心。
- 迁都与多都制使用独立时间片，不用一条记录覆盖整个政权寿命。
- 现代地名映射允许 `exact`、`approximate`、`regional`、`debated` 四类状态。
- 战国、十六国、南北朝、五代十国、宋辽金夏元、明清和近现代政权分别核验；草原、东北亚、青藏和西南政权单独处理。
- 所有记录附来源 ID；首都点不等价于直接控制范围。

## 验收标准

1. 所有 `polities` 都能找到至少一条合法首都关系。
2. 所有关系的地点 ID 都能解析，年份区间与政权寿命相交且不反向。
3. 当前年份地图能生成首都 GeoJSON 图层，且不会把无效年代地点显示出来。
4. 面板能显示历史名称和现代名称，并保留角色和来源信息。
5. 迁都、多都制、无固定首都和不确定地点都有测试覆盖。
6. 现有边界、事件、现代主权参照和多语言测试保持通过。
