# 全局语言一致性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 当前会话未提供这两个子技能，因此执行时采用同等的逐任务 TDD、检查点和代码审查流程。

**Goal:** 让地图、目录、详情和时间轴在选择任一语言后使用统一的显示规则，并将必须保留的来源原文明确标注为原文。

**Architecture:** 在现有 `LocaleProvider` 和内容本地化层之上增加结构化实体标签解析器与来源字段格式化器。地图 GeoJSON、目录和详情共用解析结果；语言纯度审计以结构化豁免区分合法原文和普通漏翻。

**Tech Stack:** React、TypeScript、MapLibre GL、OpenCC JS、Vitest、Testing Library、Vite。

## Global Constraints

- 语言为 `zh-CN`、`zh-HK`、`zh-TW`、`en`；切换不得重建地图或改变年份、镜头、图层、选择和搜索输入。
- 不在线翻译，不机器音译，不修改几何、来源URL、稳定ID、日期精度或历史结论。
- 文献原题、机构、作者、数据集、许可证、版权署名和原始来源值可以保留原文，但必须带当前语言语义标识。
- 未核验世界名称在中文中显示来源原名及“译名待核验”；英文显示来源原名。
- 当前目录没有Git仓库，不初始化仓库；计划中的“提交”步骤改为记录测试检查点。

```ts
export function resolvePolityName(polity:Polity, locale:Locale) {
  const sourceOriginal = polity.region === 'world'
    && polity.name === polity.originalName
    && !hasHanText(polity.name);
  if (sourceOriginal && locale !== 'en') {
    const pending = chineseText('译名待核验', locale);
    return {
      name: `${chineseText('原名：', locale)}${polity.name}（${chineseText('中文译名待核验', locale)}）`,
      meta: {status:'source-original' as const, sourceName:polity.name, mapLabel:`${polity.name}〔${pending}〕`},
    };
  }
  const name = locale === 'en' ? englishPolityName(polity) : chineseText(polity.name, locale);
  return {name, meta:{status:'verified' as const, sourceName:polity.originalName, mapLabel:name}};
}
```

Move `englishPolityName` and its name tables from `content.ts` into `entity-label.ts`; do not duplicate them.

- [ ] **Step 3: Implement structured audit rules**

English `ui` and verified `entity` reject Han characters.
