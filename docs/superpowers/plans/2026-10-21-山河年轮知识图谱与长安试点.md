# 山河年轮知识图谱与长安试点 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use inline execution in this session. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有历史地图基础上建立带时间、视角、来源和不确定性的关系数据层，并完成“长安/西安城市史”首个学习闭环。

**Architecture:** 保留现有 `polities`、`places`、`events`、`boundaries` 数据作为实体与专题数据；新增统一的 `HistoricalClaim` 关系层，把政权、城市、人物、事件、政策/制度、遗产和史料连接起来。内容数据与呈现/业务代码分层，通过稳定 ID、schema 和数据访问接口连接。第一阶段继续使用 TypeScript/JSON 文件适配器及派生查询，不引入图数据库；长文本、图像、地图几何和扫描件等资源按需置于独立文件/对象存储并由元数据引用。UI 通过多视角研究查询共享同一份时态关系数据，并分离地图年份、时间轴范围、阅读对象历史范围和当前章节时期。

**Tech Stack:** TypeScript, React, MapLibre GL, Vitest, GeoJSON.

## Global Constraints

- 产品定位是“带证据、时间和不确定性的历史时空知识系统”，不是单一正确的历史疆域地图。
- 所有关键关系必须带有效时间、视角、证据类型、置信度和来源 ID。
- 名义统治、实际控制、军事占领、间接影响、朝贡/册封和文化影响必须使用不同关系类型。
- 历史城市、现代城市和遗产现存状态不得混为一个实体。
- 不确定、争议、资料空白和项目未核验必须分别标记。
- 每个任务先写失败测试，再写最小生产实现。
- 领域内容不得继续嵌入页面组件或业务逻辑；当前文件存储只是实现适配器，目录、schema、ID、引用和校验约定需支持未来把结构化数据迁入数据库，并让数据库记录引用独立文件/对象存储资源。
- 不在本阶段引入数据库或绑定具体数据库产品；达到文件存储的协作、规模、检索或并发限制后再评估迁移。
- 建立以学习闭环为验收目标的多视角体验；关系图按问题选择表达，默认渐进展开，并提供可解释的下钻理由和可恢复的返回路径。
- 事件因果、人物关系和遗产现状均须有明确关系依据；区分史料记载、研究结论、项目解释、争议与当前未收录信息。
- 地图专题在适合的可用屏幕宽度下采用可拖动分隔的双栏，地图与专题并存；移动端、窄窗口、竖屏和低高度窗口采用经验证的响应式布局，并保留完整地图与阅读状态返回。
- 专题内容采用适合长文的专业排版，多模态素材与正文语境关联，具备图注、来源/权利信息、替代文本、字幕或文字稿；专题定位、改年和比较分别由用户显式触发。

## 本次方案完善后的实施路线

原计划中的断言层、人物/遗产基础模型、长安数据、政权/城市研究视图和关系面板已有阶段交付记录，详见 [`docs/2026-10-21-知识图谱与长安试点阶段验收.md`](../../2026-10-21-知识图谱与长安试点阶段验收.md)。以下是依据本次地图交互评审补充的后续路线，不把既有交付重复列为待办。开始每项实现前，重新核对代码现状和未提交修改；本文件是实施顺序与验收约束，不表示这些新增交互已经实现。

### 阶段 A：定义地图时点与时间轴语义

**范围：** `src/domain/history-state.ts`、`src/domain/types.ts`、`src/components/Timeline.tsx`、`src/components/MapView.tsx`、疆域/事件相关数据审计。

- 明确选中年份是地图查询切片；区分政权存续、疆域资料覆盖、地点可定位和事件有效期。
- 时间轴分离显示地图资料断面/资料变化、历史事件/阶段、政权与都城时期，不把数据更新节点说成历史变化。
- 明确精确断面、来源有效时段、最大范围参考、争议、候选地点和 `leave-unfilled` 的显示语义；缺年不插值、不沿用上一年图形。
- 建立地图图例与当前年份/疆域语义/图层/证据状态联动的契约。

**验收：** 年份切换后标题、疆域、地点和事件一致；缺图政权仍可查；无资料和历史不存在可区分；不支持的中间年不会由动画或缓存伪造几何。

### 阶段 B：地图对象选择与关联说明

**范围：** `src/domain/detail-views.ts`、`src/components/InfoPanel.tsx`、`src/components/EntitySummaryCard.tsx`、`src/components/EntityDrawer.tsx`、`src/components/RelationshipGraph.tsx`。

- 地图点选先高亮并生成当前年份上下文摘要，按对象类型显示身份/角色、有效期、空间或时间精度、资料状态及来源。
- 每条下钻关系提供具体理由；地点关联人物需由有时段、有地点、有角色的关系约束，不能仅凭共同政权归属带入。
- 将“点选/阅读专题/地图定位/跳转年份/时期比较”拆成独立动作，并在跳年之前明确说明目标时期。
- 事件和路线保留日期精度、阶段、定位精度；都城及中心角色支持同期并列。

**验收：** 点选本身不改变地图年份或相机；当前状态与历史完整叙述可区分；每个专题入口说明关联原因；返回可恢复此前地图和阅读上下文。

### 阶段 C：专题阅读与响应式地图双栏

**范围：** `src/workspace/WorkspacePanel.tsx`、`src/components/EntityDrawer.tsx`、`src/app/App.tsx`、`src/styles/workspace.css`、详情内容组件及其集成测试。

- 在可用宽度足够的桌面/横屏工作区，以地图栏 + 专题栏替代遮罩抽屉；初始约 55:45，分隔条可拖动、键盘调整，并限制两侧最小宽度。
- 拖动分隔条时重排地图，不改变地图年份、相机、图层、选中对象及专题滚动位置；支持专题栏收窄/展开。
- 按可用空间而非设备名称选择布局：宽屏双栏；中等宽度可调双栏；手机竖屏、窄窗口或不足以保证双侧可读的场景用单主视图；返回地图恢复完整状态。平板横竖屏、手机横竖屏、折叠屏和低高度窗口均列入验收矩阵。
- 专题正文采用长文层级与稳定的阅读宽度；图、地图/路线、史料影像、音频/视频嵌入相关章节，提供图注、来源/权利、替代文本、字幕/文字稿，不自动播放。
- 专题中的“在当前地图定位”只移动镜头；“查看发生时期”才改年份；“比较前后时期”才打开比较模式。

**验收：** 各目标屏幕形态均完成“选中对象—打开专题—定位/跳期—返回原章节与地图状态”闭环；分隔条具备鼠标、触控、键盘和可访问语义；地图与正文均可辨读，而非只检查布局无溢出。

### 阶段 D：时点比较与播放深化

**范围：** 时间轴状态、地图数据同步与新增比较视图。

- 提供可选 A/B 年并排地图，联动相机和图层；优先比较有明确史料依据的两个时点或选定历史事件前后。
- 将几何差异与资料覆盖差异分开呈现；未经史料确认的 polygon 差分不得直接标记为历史扩张/退缩。
- 播放和拖动时显示地图渲染年份及加载状态；按实际数据年份离散切换，不生成未经核验的中间形态。

**验收：** A/B 年份与证据覆盖清楚；资料缺口不被误判为历史变化；快速拖动/播放最终地图与时间游标收敛一致。

### 跨阶段验收

- 以长安城市史路径先验证城市角色、政权并存、迁都、事件阶段、人物关系、政策关联和遗产现状之间的地图解释链。
- 任何页面不得把最大范围参考、区间资料或候选地点显示为精确的当年实况。
- 历史关系和多模态素材可追溯、可独立维护；组件不硬编码内容，媒体记录保存权利/许可等元数据。
- 同一用户路径在桌面、平板、手机和低高度窗口中均可完成；不以拓展数据数量替代可学习性与证据完整性。

### Task 1: 建立时态历史断言层

**Files:**
- Modify: `src/domain/types.ts`
- Create: `src/domain/claims.ts`
- Create: `src/domain/claims.test.ts`

**Interfaces:**
- `HistoricalClaim`：`id`, `subjectId`, `predicate`, `objectId?`, `validFrom?`, `validTo?`, `datePrecision`, `perspective`, `evidenceType`, `confidence`, `sourceIds`, `uncertaintyNote?`。
- `Policy`：稳定 ID、名称、提出/决策/颁布/执行时段、提出者、执行机构、实施地区、受影响对象、结果、争议和来源；独立于事件记录。
- 内容类型定义与内容记录分开维护；数据访问经稳定接口完成，避免组件直接导入数据文件。媒体/长文本资源使用可迁移的 URI 或资源 ID，并由元数据记录来源、许可、校验值和版本。
- `claimsForEntity(claims, entityId, options?)`：按实体、年份、关系类型和视角筛选。
- `claimsAtYear(claims, year)`：返回当前年份有效的断言。
- `validateClaims(claims, entities)`：返回悬空 ID、反向区间、缺来源和缺视角问题。
