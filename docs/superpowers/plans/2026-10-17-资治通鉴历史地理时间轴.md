# 《资治通鉴》历史地理时间轴 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个离线可运行的交互式历史地理网页，让用户在前403年至959年的时间轴上选择年份，并同步查看朝代/政权、历史地域、地名和大致疆域。

**Architecture:** 使用 React + TypeScript + Vite 构建单页应用。时间轴、历史状态查询、地图渲染和详情面板通过一个共享的 `AppState` 联动；历史数据以本地 TypeScript/JSON 与 GeoJSON 保存，不依赖后端或在线地图服务。地图底图使用 `world-atlas` 的本地世界数据，历史疆域使用带时间有效期和置信度的本地 GeoJSON。

**Tech Stack:** React, TypeScript, Vite, Vitest, D3 geo, `topojson-client`, `world-atlas`, SVG/Canvas, CSS.

## Global Constraints

- 时间轴覆盖公元前403年至公元959年；内部年份使用带符号整数，界面不显示公元0年。
- 时间轴允许选择每一年；地图状态通过历史快照和状态继承解析，不重复存储每一年完整地图。
- “地域”覆盖主要历史地理单元、郡国/州府、重要城市、都城、关隘、战役地点及具有叙事价值的地名，不承诺覆盖每个村落。
- 地图使用世界地图作为空间参照，默认聚焦中国及东亚，同时保留全球关系。
- 疆域表达历史时期的大致控制范围，不等同于现代国际边界或精确测量结果。
- 数据模型必须区分直接控制、间接控制、争议范围和影响范围，并附带来源与置信说明。
- 首版使用本地结构化数据，不依赖后端服务或在线地图密钥。
- 视觉遵循深墨色背景、暖白文字、泥金结构线和朱红强调色，参考 `文字静态图示范集_v1.1暗色调/06-横屏-map-赤壁水战.png`。
- 关键历史数据必须附来源或说明；不把存在学术争议的疆域强行呈现为唯一确定结论。
