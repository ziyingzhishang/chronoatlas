# 全历史时间轴与疆域资料 Implementation Plan

**Goal:** 保留双底图和地图交互，扩展历史时间导航，替换虚构疆域轮廓，区分历史年份与资料断面。

**Architecture:** 年代目录、地理断面、地图呈现分离。只导入明确许可的开源矢量资料；原始坐标不平滑、不以现代省界拼接。断面只对当年存续的政权提供参考，不作逐年插值。未知疆域留空并列出缺口。

**Tech Stack:** React / TypeScript / MapLibre / Vitest；Node 数据导入脚本。

## Global Constraints

- 当前目录不是 Git 仓库，不创建 worktree，不提交不存在的 Git 历史。
- CHGIS V6 官方禁止再分发，不打包其数据；Hartwell 使用现代行政区拼合，也不能宣传为精确古界。
- Historical Basemaps 数据仅为大陆尺度参考；排除明显年代错标的断面，不声称学术校勘完成。
- 上古年代为约年；史前文化不是国家疆域；现代底图海岸线不等于古海岸线。
- 从前8000年至2026年可逐年导航，但不承诺每年/每个政权都有边界资料；无公元0年。
