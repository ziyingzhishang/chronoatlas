# 历史转折事件 Implementation Plan

> **For agentic workers:** Use executing-plans when available; unavailable this session. Follow test-first checkpoints with independent review. Research/data worker has a disjoint write scope.

**Goal:** 统一事件目录和快捷节点，增加可追溯、可筛选、可阅读的转折事件。

**Architecture:** HistoricalEvent 扩展详细字段；纯查询模块控制跨年匹配与事件聚合；事件面板复用工作台单一抽屉。数据资料整理独立于 UI 修改。

**Tech Stack:** TypeScript / React / Vitest；官方网页与原始文献核验。

**完成记录（2026-10-19）：** 首批26条精选事件、查询、聚合、详情与年份联动已完成；全量112项测试通过。详情直接保存在 `events.ts`，未重复创建 `event-details.ts`。具体证据、部分核验项与未覆盖时期见事件核验报告；未宣称完整历史已考证。

## Global Constraints

- 不虚构精确日期、地点或边界；来源精度不足时标明待核验／约址。
- 不承诺穷尽全历史；记录本批实际覆盖与剩余缺口。
- 新事件不会自动产生疆域；最大参考不能说成事件造成的范围变化。
