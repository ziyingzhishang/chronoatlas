# 台湾主权标注与中国疆域补全 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 当前会话未提供这两个子技能；执行时必须采用同等的逐任务 TDD、阶段检查点和独立代码审查流程。

**Goal:** 在不伪造历史国界的前提下，加入1949年至今的台湾主权标注和现代专题参照，建立A/B/C/D疆域证据体系，并逐段处理中国及周边87个政权的完全缺图、短缺口、中等缺口和长缺口。

**Architecture:** 保留现有原始导入数据，新增结构化 `BoundaryEvidence`、独立的现代主权参照源、可审计的缺口决策账本和生成型补充疆域文件。运行时只按证据记录选择和呈现几何；C级只能来自同一政权的显式决策，D级使用点、柔边或影响范围，不进入“确定疆域”统计。公开发布合规与普通开发构建分离，未取得审图号时产品可以本地研究使用，但发布门禁必须失败。

**Tech Stack:** React 18、TypeScript、MapLibre GL 6、GeoJSON/TopoJSON、d3-geo、OpenCC JS、Vitest、Testing Library、Node 24、Vite 6。

## Global Constraints

- 现代主权语义与历史实际控制图层分离；不得把1949年后的主权标注反向写入古代疆域。
- 台湾省现代专题参照与中国大陆使用同一中国专题组；1949年前不显示该现代覆盖，但地图阅读说明可随时查看。
- 不从未授权地图描边，不导入只有截图、无版本、无许可或不可重发布的几何。
- A/B级才计入“有确定疆域资料”；C级明确显示“过渡参考”或“最大参考”；D级明确显示“文化核心／控制中心／影响范围，非确定国界”。
- 1—5年缺口也不得自动批量填充。每段必须在决策账本中写明同一政权、历史转折检查、来源记录和处理结论。
- 6年以上缺口不得用最近年份自动桥接。没有可重发布几何时允许保留专题研究结论，但界面必须准确说明未形成确定国界。
- 夏代只显示二里头文化核心参照；更始政权只显示可核验的宛、洛阳、长安控制中心，不生成封闭国家边界。
- 中国及周边87个政权完成后，再另立计划按世纪推进1,458个同期世界实体；本计划不改写世界分块几何。
- 四语言为 `zh-CN`、`zh-HK`、`zh-TW`、`en`；来源原文保留原文并带当前语言标签。
- 当前目录不是Git仓库，不初始化仓库；每个任务以测试命令、生成文件哈希和验收文档作为检查点。
