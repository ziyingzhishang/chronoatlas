# 山河年轮知识图谱详情抽屉与长安完整示范 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use the project’s approved subagent workflow when expert slots are available; otherwise execute task-by-task inline with review checkpoints. Every task must end with focused tests and a commit.

**Goal:** 建立统一的实体详情抽屉、完整人物/事件/遗产详情模型和长安／西安完整知识图谱示范。

**Architecture:** 保留基础实体与时态断言作为核心数据层，新增详情目录和详情视图构建层；React 使用统一 `EntityDrawer` 承载人物、事件、遗产、政权和地点详情，摘要卡只负责导航。关系图和城市历史时间轴通过详情视图模型消费同一套带时间、来源和不确定性的断言。

**Tech Stack:** React 19, TypeScript, Vitest, Testing Library, 现有 CSS、MapLibre 和 locale 系统；不新增图谱或 UI 依赖。

## Global Constraints

- 关系必须带方向、有效年代、证据类型、置信度和来源。
- 没有来源或无法确认的内容必须显示不确定性，不得伪装成确定史实。
- 桌面详情抽屉宽度约为视口 50%，最大宽度 760px；移动端全屏。
- 摘要卡不承载完整长文，完整信息进入详情抽屉。
- 图形关系网络必须同时提供文本清单。
- 第一阶段只以长安／西安为完整示范，之后复制到其他城市和全部政权。
- 每个任务先写失败测试，再实现最小代码，最后运行定向测试并提交。
