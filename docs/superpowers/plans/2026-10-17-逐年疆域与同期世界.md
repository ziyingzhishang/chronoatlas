# 逐年疆域与同期世界 Implementation Plan

> **For agentic workers:** 按本清单在当前会话逐项实施，独立审查数据规则及最终代码。当前目录不是 Git 仓库，不创建提交或隔离工作树。

**Goal:** 补齐可获得且许可明确的中国历史疆域，按来源时段响应逐年选择，并提供最大已收录范围补缺和同期世界图层。

**Architecture:** 引入固定版本 Cliopatria v0.2.1（CC BY 4.0），保留原始几何、原始名称及来源起止年。中国目录逐项映射并限制在政权存续期；世界按世纪分片按需载入，排除联盟/上层汇总重复面。数据时段不是逐年考证结论，缺年可取同政权已收录记录中面积最大的单个轮廓，绝不跨朝拼接。

**Tech Stack:** React / TypeScript / MapLibre / Vitest；Node 24 可复现导入脚本。

## Global Constraints

- 继续使用用户已批准的地图和时间轴设计；不重做真实地形底图或手势。
- 年份无 0 年；不把邻近断面、来源时段或最大范围称为逐年精确边界。
- 最大范围仅表示本数据集中最大的单个时段图形，不能断言历史真实极大值；界面说明来源年代、计算面积及叠置风险。
- 商周早期范围为约略范围；夏等无适用资料的缺口保留并解释。
- 不把蒙古全帝国改名为元，不把新、武周等默认为汉、唐；错误或疑似异常记录列入排除清单。
- 世界层保留原文名称及所属关系；不是已逐国完成历史核验的国界权威图。
- 全部导入数据必须有出处、许可、哈希、变换记录与逐政权覆盖清单。
