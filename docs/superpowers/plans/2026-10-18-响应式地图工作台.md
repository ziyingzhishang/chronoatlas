# 响应式地图工作台 Implementation Plan

> **For agentic workers:** Use executing-plans when available; it is unavailable in this session, so execute inline with test-first checkpoints and independent review.

**Goal:** 在干净的地图工作台内完成年份调整，支持桌面停靠／悬浮与手机三档控制器。

**Architecture:** 保留 App 的唯一年份状态和 MapView 地图实例。工作台壳管理单一辅助面板，TimeController 管理尺寸、密度及位置；纯函数管理视窗规则、坐标限制和存储校验。

**Tech Stack:** React 18 / TypeScript / MapLibre / Vitest / Testing Library；无新增运行依赖。

**完成记录（2026-10-19）：** 本轮已实施，112项测试及生产构建通过；独立复核确认四项P2修复。下列检查项按任务目标验收，实际组件接口与初稿的差异、安全区及屏幕记录见 `docs/2026-10-19-工作台与事件验收.md`。未执行远端发布。

## Global Constraints

- 用户已批准两份 2026-10-18 设计，目标为独立网页应用，不发布、不接入微信。
- 地图镜头、年份和底图不因布局变化重置；必要署名及数据不确定性可见。
- 不新增历史疆域，不改变最大参考推断；手机正文可滚动，常用触控目标约 44px。
- 当前不是 Git 仓库，不创建仓库或提交；基线 66 个测试通过。
