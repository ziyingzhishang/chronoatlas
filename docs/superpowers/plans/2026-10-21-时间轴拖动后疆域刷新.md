# 时间轴拖动后疆域可靠刷新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让快速连续拖动时间轴时的地图始终收敛到最终年份，并避免同期世界大数据阻塞中国及周边疆域刷新。

**Architecture:** 将中国及周边疆域与同期世界疆域拆为独立 MapLibre GeoJSON sources；用带修订号的最新值协调器合并连续更新，并通过时间轴预览／提交协议强制同步最终年份。地图暴露只读 `data-rendered-year` 与 `aria-busy`，使竞态可以自动测试和浏览器验收。

**Tech Stack:** React 18、TypeScript、MapLibre GL 6、Vitest、Testing Library、Vite 6。

## Global Constraints

- 不修改任何历史疆域几何、年代、证据等级或主权文案。
- 年份切换不得调用 `flyTo`、`easeTo`、`fitBounds`，不得重建 MapLibre 实例。
- 中国及周边疆域必须优先于同期世界疆域提交。
- 世界分块加载中或跨世纪切换时，旧世界图形必须清空且不得覆盖新年份。
- 拖动结束后两秒内 `data-year` 与 `data-rendered-year` 必须一致。
- 不增加常驻视觉控件；仅使用 `aria-busy` 与只读 data 属性表示刷新状态。
- 当前目录不是 Git 仓库，不初始化仓库；以 RED/GREEN 命令、生产构建和浏览器截图作为检查点。

```ts
export function createLatestFrameUpdater<T>(
  apply:(value:T, revision:number)=>void,
  schedule:(fn:FrameRequestCallback)=>number=requestAnimationFrame,
  cancel:(id:number)=>void=cancelAnimationFrame,
) {
  let frame:number|undefined;
  let latest:T;
  let revision=0;
  let disposed=false;
  const run=()=>{
    frame=undefined;
    if (!disposed) apply(latest, revision);
  };
  return {
    push(value:T) {
      if (disposed) return revision;
      latest=value;
      revision++;
      if (frame===undefined) frame=schedule(run);
      return revision;
    },
    flush(value:T) {
      if (disposed) return revision;
      latest=value;
      revision++;
      if (frame!==undefined) cancel(frame);
      run();
      return revision;
    },
    dispose() {
      disposed=true;
      if (frame!==undefined) cancel(frame);
      frame=undefined;
    },
  };
}
```
