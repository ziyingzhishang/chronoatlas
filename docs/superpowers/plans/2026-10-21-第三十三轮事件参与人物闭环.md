# 第三十三轮事件参与人物闭环实施计划

**目标：** 为屋大维获奥古斯都称号、君士坦丁堡陷落、哥伦布抵达加勒比、威斯特伐利亚和约、联合国成立建立有来源、带阶段边界的人物参与闭环。

**范围：** 仅修改人物目录、人物详情、人物关系 claims、事件详情、事件来源与本轮专项测试；不修改地点、首都或地点关联文件。

**实施：** 先以专项测试锁定五个事件的人物端点和证据要求，再补最小可核验人物集合；每个人物必须同时拥有 people、person-details、至少一条事件 claim，并在能确认时补充人物关系。事件参与者必须有角色、阶段说明和不确定性说明。

**验收：** 运行第三十三轮专项测试、全量测试、构建和 `git diff --check`；检查 diff 不包含地点关联文件后提交。
