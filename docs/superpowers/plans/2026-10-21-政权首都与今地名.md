# 政权首都与今地名补全 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use inline execution in this session. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为全部目录政权建立可核验的首都/政治中心沿革数据，并在当前年份地图与信息面板中显示历史首都名及现代地名。

**Architecture:** 新增独立 `capital-history.ts` 关系表，保留 `Polity.capitalPlaceId` 兼容现有消费者；扩展 `Place` 的现代映射元数据；地图数据层生成独立的 `capitalPlaces` GeoJSON，UI 通过独立图层和面板字段消费。首都关系只描述政治中心，不参与疆域几何计算。

**Tech Stack:** TypeScript, React, MapLibre GL, Vitest, GeoJSON.

## Global Constraints

- 全部首都记录必须有来源 ID和置信度。
- 迁都、多都制、临时首都和政治中心必须使用时间区间与角色表达。
- 不确定的古城定位必须标注，不得伪装成精确坐标。
- 不修改疆域几何的历史证据或现代主权参照层。
- 先写失败测试，确认失败后再写生产代码。
