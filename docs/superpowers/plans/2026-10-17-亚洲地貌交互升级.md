# 亚洲地貌交互升级 Implementation Plan

> **For agentic workers:** 按下面任务在当前会话实施并验证；用户已选择两种真实底图及缩放、旋转交互。工作目录无 Git 仓库，不创建分支或提交。

**Goal:** 正式页面默认聚焦亚洲，提供地形晕渲、自然色卫星切换，以及缩放、平移、旋转、俯仰、复位。

**Architecture:** 用 MapLibre GL JS 替换固定 SVG 地图。React 保留年代、选择和图层状态；地图实例只初始化一次，历史 GeoJSON 随年份更新，底图仅调整可见性，保留相机状态。底图加载失败仍保留本地陆地与历史覆盖层。

**Tech Stack:** React / TypeScript / MapLibre GL JS 6.14 / Esri raster tiles / Vitest。安装检查发现 5.x 的已知安全问题，改用已修复版本并重新验证兼容性。

## Global Constraints

- 两种底图均来自真实现代地形或影像，不将现代地表标为古代复原。
- 保留现有历史数据、年份范围、疆域不确定性和详情面板。
- 无需密钥；在线瓦片注明来源，网络失败显示重试入口。
- 桌面、触屏、键盘均提供操作途径；中文地名避免重叠。
- 不将俯仰视角称为高程驱动的三维地形。

**Interfaces:** `buildMapData(state: HistoricalState)` 返回 boundaries、places、polityLabels、events GeoJSON；`createMapStyle()` 返回 `StyleSpecification`；`Basemap = 'relief' | 'satellite'`。

- [x] 安装 MapLibre GL JS，使用显式样式定义，无外部样式或字体服务依赖。
- [x] 添加两个 raster sources 与本地 world-atlas 土地层；source 使用 URL 的 `{z}/{y}/{x}` 顺序、256px tileSize 和来源署名。
- [x] 添加疆域填充、描边、中文政权/地名标签、现代参照与事件圈。中文标签使用本地字体与碰撞检测。
- [x] 检查 GeoJSON 的政权 ID、置信度、选择 ID 以及已选年份是否保留。例如：

```ts
const data = buildMapData(getHistoricalState(-221));
expect(data.boundaries.features.some(f => f.properties?.polityId === 'qin')).toBe(true);
expect(buildMapData(getHistoricalState(959)).boundaries.features.some(f => f.properties?.polityId === 'qin')).toBe(false);
```
