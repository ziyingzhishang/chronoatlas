# 疆域可读性与多语言 Implementation Plan

> 执行方式：本会话分批执行与测试检查点，独立文件范围并行。executing-plans/subagent-driven-development 未列为可用技能，使用已读取的 TDD 与 parallel-agents 流程替代。

**Goal:** 改善卫星疆域识别度，并提供四种显示语言，不改变历史事实与查询状态。

**Architecture:** 语言 Context 管理偏好，纯文本词典和实体本地化函数供组件及地图共用。底图样式函数独立于历史几何。内容资源与界面组件分离。

**Tech Stack:** React、TypeScript、MapLibre、Vitest，沿用现有工程。

## Global Constraints

- 设计文档 `2026-10-19-疆域可读性与多语言-design.md` 已获批准。
- 语言 zh-CN / zh-HK / zh-TW / en；默认 zh-CN，未核实世界名称原名回退。
- 不复制几何，不在线翻译，不重建地图；保留来源署名、不确定性及原文标题。
- 无Git仓库，不初始化或提交。先失败测试后实现；完整测试与构建后验收。
