# 首都关联遗产覆盖边界审计

## 审计范围

本轮以 `capital-history.ts` 中出现的地点为首都关联地点集合，将 `heritage.ts` 中 `placeId` 命中该集合的遗产纳入审计。当前共有 66 个首都地点、106 条首都关联遗产；遗产总数为 108 条，另有 2 条不命中首都地点集合。

每条首都关联遗产均检查以下证据门槛：

1. `placeId` 能解析到地点目录，并有非空现代地点说明；
2. 有历史关联、至少一个历史沿革阶段、存续特征和当代价值；
3. 遗产、详情和各历史阶段的来源 ID 均能解析到来源目录；
4. 关联政权端点均能解析到政权目录；
5. 关联事件端点能解析到事件目录，或被列入本轮明确冻结的边界集合；
6. 有非空不确定性说明，尤其标明跨政权、叠压层、迁移、约址或现存建筑与原构不可等同的情况。

## 结果

106 条首都关联遗产全部具备现代地点、历史沿革、来源、政权端点和不确定性说明。详情覆盖没有 `data-missing` 条目；所有遗产及阶段来源均可解析。

其中 101 条为 `complete`，5 条为 `needs-review`。五条 `needs-review` 为：

| 遗产 ID | 当前边界 | 不能闭合的原因 |
| --- | --- | --- |
| `big-wild-goose-pagoda` | 唐代大慈恩寺与塔院，历代修缮 | `xuanzang-translations` 尚无事件目录端点；不能把建筑年代拼接成译经事件 |
| `qinglong-temple-site` | 唐代寺院遗址与现代纪念空间 | 同上；唐代原址、后世建筑和现代园林需分层 |
| `xian-beilin` | 后世碑刻收藏与展示空间 | 同上；碑刻原址、刻立年代和后世编次不能还原成单一译经事件 |
| `xiao-yan-ta` | 唐代荐福寺小雁塔及后世维修层 | 同上；始建年代和现存构件不能替代译经事件端点 |
| `ximing-temple-site` | 西明寺相关区域，现代标注为约址 | 同上；已有西明寺营建和玄奘阶段专属事件，但不足以生成跨五处遗产的统一译经事件 |

这五条的共同不确定性说明已写入遗产详情：当前资料缺少可共同适用于五处遗产的统一起止年代、地点集合、阶段链和独立来源。因此本轮不新增事件端点、不把 `needs-review` 改为 `complete`，也不把西明寺约址升级为确定地点。

## 不修改项与后续关闭门槛

本轮不修改生产数据，也不修改 `claims.ts`、人物详情、政权详情或既有基线测试。独立回归测试为 `src/data/capital-heritage-boundary.audit.test.ts`。

只有同时获得以下证据，才可关闭对应事件边界：

- 独立且可解析的事件端点；
- 明确的事件起止年代与地点集合；
- 能覆盖相关遗产阶段的独立来源；
- 不把跨政权、跨阶段遗产或约址写成单一确定事实；
- 不与现有专属事件重复，也不以建筑营建年代代替译经事件年代。

## 验证

针对性测试覆盖：

- 106 条首都关联遗产的字段与来源完整性；
- 政权端点和地点端点解析；
- 101 条 `complete` 与 5 条 `needs-review` 的精确分类；
- `xuanzang-translations` 未收录时的五条显式边界及审计备注；
- 无 `data-missing` 条目，来源覆盖率保持 100%。
