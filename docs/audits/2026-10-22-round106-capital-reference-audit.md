# 第106轮首都节点引用审计

## 审计范围

本轮复核第105轮审计列出的29项候选，只接受同时满足以下条件的引用闭环：

- `capitalHistory` 中存在明确的政权、地点和有效年代；
- 事件或遗产拥有独立端点，且其政权归属字段明确指向该政权；
- 事件地点或遗产地点与该首都阶段一致；
- 年代落在首都阶段内；
- 政权详情确实缺少该引用，且补录不会把同城、跨阶段关系误写成政权关系。

## 本轮闭环

### 秦—咸阳—统一完成事件

闭合 `qin-xianyang-unification` → 秦政权详情的事件引用。

- 首都端点：秦帝国 `qin`，咸阳 `xianyang`，前221—前206年；置信度为 high、formal。
- 事件端点：`qin-xianyang-unification`，前221年，地点为咸阳。
- 事件详情端点：`polityIds` 明确包含 `qin`，`locationIds` 明确包含 `xianyang`。
- 年代一致：前221年落在秦帝国咸阳首都阶段内。
- 变更：仅将该事件 ID 补入秦政权详情 `eventIds`；事件、首都记录和遗产记录未改写。

对应回归测试为 `src/data/capital-reference-round106.audit.test.ts`。

## 未闭合项

第105轮候选清单剩余28项。本轮没有根据“同城”单独补录以下类型：跨政权或跨首都阶段事件、遗产构成年代与政权阶段不充分重合的项目、以及需要把城市一般历史层反推为政权专属遗产的项目。后续仍需逐项取得独立政权归属和时间证据后再处理。
