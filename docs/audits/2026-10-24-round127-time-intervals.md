# 第127轮专家团：人物活动区间与都城阶段时间校核

本轮按“生卒年、任职/活动区间、政权或城市阶段”分层处理，不用人物任职区间倒推生年，也不把宽泛的政权建立事件改写成精确建国日。

## 已实施

| 对象 | 调整 | 口径 |
| --- | --- | --- |
| 秦穆公 | 秦国国君前659—前621年 | 在位区间；生年不写入人物本体 |
| 冒顿 | 匈奴单于前209—前174年 | 约年活动窗口；草原政治中心具有流动性 |
| 张骞 | 两次出使：前138—前126年、前119—前115年 | 使者活动区间；不等同于完整任职或生卒 |
| 蒙恬 | 秦将与北方防务统帅前215—前210年 | 约年军事活动窗口 |
| 武丁 | 商王约前1250—前1192年 | 晚商分期约年；不据此断言精确王年 |
| 刘曜 | 补充329年卒年 | 生年仍未知 |
| 呼韩邪单于 | 补充前31年卒年 | 生年仍未知 |
| 高句丽平壤都城 | 427—585年；586年起另列长安城阶段至668年 | 纠正“平壤持续至灭亡”的过度延伸 |

## 证据与边界

本轮新增《史记·匈奴列传》《史记·大宛列传》《史记·蒙恬列传》《晋书·刘曜载记》《汉书·匈奴传》来源条目。活动区间用于人物详情、关系图谱和时间轴定位；人物时间覆盖仍要求完整生卒年才进入 `confirmed`，因此不会因为本轮补了活动区间而虚增生卒完整度。

高句丽迁都平壤事件的详情阶段采用427年迁都、586年转入长安城、668年政权终结的分层表达；平壤仍保留为城市视角的重要历史节点，但不再被误显示为427—668年持续唯一都城。
