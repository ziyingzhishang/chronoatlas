# 第122轮：隋—东都洛阳—定鼎门遗址政权视角闭环

## 结论

本轮闭合一项首都视角遗产关联：`dingding-gate-site` 位于今洛阳，结构化营建起点为605年，且遗产详情明确将其作为隋营建东都时形成的外郭城正南门及城市轴线节点。隋首都阶段为605—618年，因此将该遗产加入 `sui` 政权详情，使“隋—东都洛阳—定鼎门遗址”的城市视角链可从隋政权抽屉直接访问。

## 边界

- 本轮只补充隋政权与遗产的显式关联，不把定鼎门现存展示工程当作隋代原构。
- `dingding-gate-site` 同时属于唐代洛阳城市历史层；本轮不删除唐关联，也不把605年解释为唐代事件。
- 没有新增未经独立核验的人物、工程负责人或精确宫门坐标。
- 长安的太极宫、含光门、明德门仍保留为“分层首都遗产”待继续逐项核验，不因本轮洛阳闭环而批量关闭。

## 验证

- `capital-reference-round114.residual-categories.test.ts` 断言残余集合从16项降为15项。
- 相关遗产详情仍以605—907年考古层表达隋唐沿用，现代遗址公园与隋唐原建筑分层展示。
