## 总体结果

- 范围维持现有 90 段 coverage 台账：10 段试点作为优先标记，之后仍分别归入第二批 28 段、第三批 36 段、第四批 26 段；试点与批次计数不重复相加。
- 90 段展开为 1451 条有效公历年记录。每年均有年度结论、至少一个可追溯来源 ID 或明确证据缺口；不含公元 0 年。
- 86 个含年度记录的专题 JSON 关联全部 90 条 coverage 决策，均为 `source-checked`；其中三国形成、三国终止、后燕／后秦建政、明／北元形成四份共时审计各对应两条决策。1451 条有效公历年均有逐年结论，表达包括中心点、文化核心等其他参照表达、明确留空和仅保留历史结论。
