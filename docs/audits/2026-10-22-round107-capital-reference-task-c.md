# 第107轮首都链路任务 C 审计

## 范围与硬性边界

本轮只复核剩余候选中的五代、宋、高句丽、东周、后凉组。闭合条件为：首都阶段同时提供政权、地点和年代；事件或遗产拥有独立端点；事件详情或遗产详情明确提供政权归属；地点与首都阶段一致；年代落在首都阶段内。不得仅因同城、共享城市考古层或后世承接关系补录。

## 本轮唯一闭合项

### 南宋—临安—临安中心形成（1138）

将 `song-linan-center-formed` 补入 `song_south` 政权详情的 `eventIds`。

- 首都阶段：`song_south`—`linan`，1127—1279，正式长期政治中心阶段。
- 事件端点：`events` 中事件年份为 1138，地点为 `linan`。
- 事件详情端点：`polityIds` 明确包含 `song_south`，`locationIds` 明确包含 `linan`，并以独立来源说明南渡后的中心形成过程。
- 语义边界：该事件只表示临安长期中心形成，不把 1138 年回写成南宋建政日，也不抹去应天、扬州、建康的前置阶段。

对应回归测试：`src/data/capital-reference-round107.task-c.test.ts`。
