# 第117轮白马寺创建事件补全

## 本轮闭合

白马寺 `white-horse-temple` 新增独立事件端点 `white-horse-temple-founded`：

- 年代：68年（东汉永平十一年）
- 地点：洛阳，今洛阳市白马寺镇
- 政权视角：东汉
- 来源：文化和旅游部、洛阳市人民政府

这使“东汉创建传统”可以作为可点击的事件详情展示，而不再借用东汉建政或洛阳迁都事件。

## 保留的城市视角边界

白马寺遗产仍关联东汉与唐，原因是今日遗产是长期寺院沿革、历代重修和城市宗教网络的叠合对象。新增东汉创建事件不等于把现存建筑全部标为东汉原构，也不把白马寺整体补入东汉政权详情。
