# 第108轮任务B：隋唐遗产复核

## 复核范围

本轮继续复核第107轮列出的隋唐首都遗产候选。闭合条件为：

1. 遗产详情明确归属单一目标政权，不能是隋唐叠压遗址被人为拆分出的单政权事实；
2. 有明确城市地点，并与目标政权首都阶段相交；
3. 有明确历史年代；
4. 遗产资产和详情均有可解析来源。

本轮最多闭合一项；不以遗产关联反推缺失的事件端点。

## 本轮安全闭合（1项）

### 唐—长安—小雁塔

闭合 `xiao-yan-ta` → 唐政权详情的遗产引用。

- 单一政权归属：详情 `associatedPolities` 仅为 `tang`，没有把隋代寺院前身或其他政权写入该遗产关联。
- 城市端点：资产和详情均指向 `changan`，现代位置为今西安市碑林区荐福寺旧址一带。
- 年代端点：资产始建年为707年，详情原建筑阶段为707—710年；唐长安首都阶段为618—907年，年代相交。
- 来源端点：资产补充 `xiao-yan-ta-official-digital`，详情保留《资治通鉴》、现代地理参照和专门数字展示来源；来源 ID 均可解析。
- 变更：将遗产资产的专门来源补入 `sourceIds`，并将 `xiao-yan-ta` 补入唐政权详情 `heritageIds`。

小雁塔的 `xuanzang-translations` 仍是待核关联。本轮只闭合遗产—政权—城市—年代—来源链，不把未解析事件转换成事实，也不据建筑年代补录译经事件。
