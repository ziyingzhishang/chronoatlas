# 城市时间轴证据状态审计

## 范围

本轮只审查并增强 `CityHistoryTimeline` 与 `city-timeline` domain。目标是让城市视角节点显示已有关系、事件、遗产记录的证据状态，同时保留原实体详情抽屉入口。

## 实施结论

- 时间轴节点新增证据摘要：关系数量、来源状态与数量、已有时间精度、不确定性记录状态。
- 政权、人物、地点复用实体与资本关系已有来源；事件复用事件及事件详情已有来源、事件时间精度和不确定性；遗产复用遗产与城市关系已有来源。
- 关系时间精度和不确定性只读取已有 claim；未记录的字段显示为未记录，不从年份区间推断精度。
- 无来源 ID 的记录显示“来源：待解析”；没有时间精度或不确定性说明时分别显示未记录。
- 使用原生 `details/summary` 展开证据摘要，摘要可由键盘聚焦；节点名称仍是原有实体按钮，继续调用 `onOpenEntity`。

## 边界

- 本轮没有新增或修改历史人物、事件、遗产、关系或来源数据。
- 本轮没有修改 `InfoPanel`、`KnowledgeCoveragePanel`、`claims` 或事件/遗产数据。
- 遗产没有独立时间精度字段时，不把 `constructionFrom`/`constructionTo` 推断成精度；仅展示其现有关系证据的时间精度。
- “来源：可用”表示记录中存在来源 ID；来源 ID 的具体解析仍由详情组件和现有来源目录负责。

- `src/components/CityHistoryTimeline.test.tsx`：摘要展示、原生键盘可达展开、实体抽屉回调通过。
- 生产构建通过，`git diff --check` 通过。
