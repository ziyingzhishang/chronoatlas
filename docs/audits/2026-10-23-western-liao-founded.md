# 西辽 `western-liao-founded` 数据闭环审计

## 结论

- `1124` 保持为政权形成的约年：它表示耶律大石自立为王并向西行进的建政过程锚点，不表示一个可精确到日的单一事件，也不把后来的中亚控制范围前推到该年。
- `1132` 单列为称帝／叶密立阶段：项目采用《辽史》相关纪年换算的常用表达，同时保留纪年换算存在异说的说明。
- `1134` 作为巴拉沙衮（八剌沙衮／虎思斡耳朵）稳定政治中心起点：依据《辽史》“延庆三年建都城、号虎思斡耳朵”的层次，与 `1132` 称帝节点分离。
- 现代地点采用“吉尔吉斯斯坦楚河州托克马克附近、布拉纳遗址（巴拉沙衮对应区域）”的区域性映射；不把遗址现存建筑直接等同于西辽宫城原貌。

## 已闭环的数据面

- 事件：补充 1124 西行建政、1132 称帝、1134 建都／政治中心稳定化的阶段、参与人物、因果、地点和不确定性说明。
- 人物关系：耶律大石、耶律夷列相关治理关系补入《辽史》与 Iranica 来源链；人物详情补充巴拉沙衮地点关联。
- 首都：西辽首都记录从“1124—1218”修正为“1134—1218，de facto／actual”，并保留 1132 过渡阶段说明。
- 地点：`balasagun` 补充楚河州托克马克附近的现代行政／区域描述、遗址映射和来源链。
- 遗产：巴拉沙衮相关遗产的历史阶段起点改为 1134，补充布拉纳遗址的现存特征与历史关联边界。
- 审计与测试：新增西辽专项测试，覆盖约年判断、三阶段时间线、首都现代地点、遗产、人物关系和来源 ID 可解析性。
