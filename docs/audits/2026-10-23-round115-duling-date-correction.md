# 第115轮杜陵营建年代修正

## 修正内容

杜陵 `du-ling` 的旧数据把营建起点写为前74年。前74年是刘询即位、成为汉宣帝的年份，不是杜陵营建年份。

本轮根据《陕西省志·建设志》杜陵条目，将杜陵营建起点和遗产原始阶段统一修正为前65年（元康元年）。同时新增 `xian-local-chronicle-duling` 来源，并在不确定性说明中明确区分“即位年”和“营建年”。

## 建模边界

- 仍保留杜陵与西汉政权的遗产关联，但不把杜陵自动补入西汉政权详情；帝陵营建事件仍缺少独立事件节点及人物—事件链的完整建模。
- 首都阶段只负责确认杜陵与长安阶段的时间重合，不由时间重合推导政权专属事件。
- 现代地点继续使用长安城市视角，杜陵的今地为西安市雁塔区曲江一带；现代行政边界不替代汉代陵园范围。
