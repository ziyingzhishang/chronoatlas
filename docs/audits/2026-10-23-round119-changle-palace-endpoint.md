# 第119轮长乐宫营建端点闭合审计

本轮针对第114轮唯一“营建事件端点未闭合”的 `changle-palace-site` 复核。史料把营建启动与建成分开记录：高祖五年开始治理长乐宫，高祖七年二月记为“长乐宫成”；高祖八年萧丞相营作未央宫另列，不能将未央宫营建责任转写为长乐宫。

## 实施结果

| 对象 | 处理 | 结论 |
| --- | --- | --- |
| `changle-palace-built` | 新增前202年启动、前200年建成两个阶段；地点使用 `changan`；政权使用 `han_western`；人物仅关联刘邦 | 长乐宫拥有独立、可解释的营建端点 |
| `changle-palace-site` | `associatedEvents` 增加 `changle-palace-built`；保留西汉、新朝双政权关联 | 遗产详情可展示事件链，但仍不压缩为单一政权遗产 |
| `han_western` | 增加事件索引和前200年转折点；不增加长乐宫遗产 ID | 西汉视角可追踪长乐宫建成，跨政权遗产边界保持不变 |

## 证据与边界

- 《史记·高祖本纪》记载高祖七年二月长乐宫建成，并在高祖八年另载萧丞相营作未央宫。
- 前202年只作为营建启动阶段，前200年作为“长乐宫成”的建成端点；两者不合并为一个模糊年份。
- 当前事件使用长安作为历史城市参照，不以长安城点位替代宫殿遗址考古测绘。
- 长乐宫继续关联新朝，是跨政权城市遗产；事件端点闭合不等于应将遗产整体并入西汉政权详情。

## 验证

- 长乐宫首都关联回归测试通过。
- 事件详情覆盖审计不再产生未解析事件或来源。
- 全量测试与构建需在本轮提交前复核。
