# 人物关系来源链接审计

日期：2026-10-23

## 修复范围

人物详情中的关系项现在直接解析关系声明的 `sourceIds`，从来源目录读取对应 `SourceNote`：

- `urlOrCitation` 以 `http://` 或 `https://` 开头时，来源标题渲染为独立的外部链接，带有 `target="_blank"` 与 `rel="noreferrer"`，可通过键盘聚焦和激活。
- 非 URL 的书目或出处保留为普通文本，并显示其书目信息，不创建伪链接。
- 关系目标继续由原有按钮打开人物、政权、事件或遗产抽屉；来源链接与目标按钮保持并列，避免嵌套交互控件。
- 关系类型、方向、有效期、时间精度、证据类型、可信度、来源可解析状态和不确定性文本均保持展示。

## 验证

- URL 来源关系：验证外链地址、`target`、`rel` 及可访问链接角色。
- 非 URL 书目关系：验证书目文本存在且不存在同名链接。
- 目标实体导航：保留既有关系按钮导航测试。

## 边界

本次只修改人物详情组件、对应测试、必要 i18n 文案和本审计文档；未修改 `claims`、`sources` 或其他组件。
