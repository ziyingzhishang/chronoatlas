# 南陈—北周建政初期并存断面复核（557—560）

本专题将南方建康与西部关中长安分别校对。此时北方的北齐仍然并存；北齐使用的 Cliopatria record 2068 覆盖555—560年，但置信度低、控制性质未标明，因此地图说明将其标为时段参考，不解读为已校定的直接疆界。本条不以两个都城点替代南陈、北周或北齐之间的边界。

逐年结论数据： [南陈 557—560 年](southern-chen-founding-557-560.json)、[北周 557—560 年](northern-zhou-founding-557-560.json)。

## 处理结论

- `gap-chen_southern-557-560` 与 `gap-zhou_northern-557-560` 均维持 `leave-unfilled`，两段均不生成疆域面。
- Cliopatria record 2080（南梁，555—557）及record 2099（西魏，555—557）都跨越557年政权交替，且控制语义未定；两条来源面仅在557年挂 `requires-review` 并从运行时拦截。保留原几何，555—556年仍按原始来源时段显示，不裁剪或转归。
- 南陈显示建康D级中心点，北周显示长安D级中心点；两点分属不同政权，不能连线或形成控制范围。
- 北齐为同期并存政权；多政权冲突区不自动裁切或按邻年几何分配。
- 555—560年北齐来源几何保持原始形状；低置信、控制性质未定的模型只作为来源时段参考，不转述为已核实的直接控制界。
- 不把557年后的政权疆域轮廓倒填回政权转换当年；来源使用权及公开地图条件另行核查。

## 来源与审核

- 《资治通鉴》卷167《陈纪一》记557—559年，卷168《陈纪二》记560年；分别核对北周建政、陈朝建立及两政权早期继承节点。
- 《周书》卷2—3、《陈书》卷1—2用于核验北周与南陈帝纪和都城承接。
- 长安、建康采用项目地点目录中的现代近似城市点。史料能支持中心与政权更替，不能单靠这些材料恢复逐年疆域边界。
