# 387—393 年并存政权来源轮廓逐年复核

逐年来源记录、内部相交配对与运行时处理见[机器可读审核记录](./coeval-boundary-overlaps-387-393.json)。

## 发现与处理

- 逐年检查每年有效的十个 Cliopatria v0.2.1 来源轮廓。387—391 年未发现内部面积相交；392、393 年各发现一对：东晋与高句丽来源轮廓。
- 只将这两条相交来源面在 392—393 年标记 `requires-review` 并从运行时地图暂缓；原始几何与来源有效时段不变，不裁切、不转归。
- 边界接触不计作面内重叠。早期扫描产生的 387 年重叠拦截已经撤销；不相交年份恢复原始来源面表达。
- 该筛查不证明来源轮廓是正确的年度历史疆界。Cliopatria 条目为低置信度时段模型，历史适用性、控制性质、来源权利和公开展示条件仍需分别审核。

## 方法与限制

对有效年份内的 GeoJSON 经度、纬度多边形，检查严格位于另一多边形内部的边界采样点及严格线段交叉；仅边界接触不计面积重叠。筛查仅用于触发复核，不判断谁控制交叠区域，也不重建疆界。
