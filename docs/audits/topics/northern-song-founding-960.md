# 北宋建政年疆域复核（960）

## 结论

960 年疆界几何继续留空；地图新增开封政治中心 D 级参照点。后周于当年禅代，赵匡胤回师开封受禅建宋。宋初仍与辽、北汉及南方诸政权并存，统一战争延续多年。史料足以支持建政节点和都城中心，但不足以将都城、战事或后世统一范围转换为 960 全年的连续边界。

《宋史》卷一《太祖本纪》记载显德七年（960）陈桥驿兵变、回师开封及受禅即位；《续资治通鉴长编》卷一《建隆元年》记录宋初与辽、北汉及南方诸政权的往来和军事行动。地图点采用项目已有开封近似坐标，仅表达中央政治中心，不是城垣、兵变地点或疆域范围。

## 记录与审核边界

- 历史来源审核：已核对《宋史》卷1及《续资治通鉴长编》卷1，来源用途与960年年内政权更替、边界限制已写入机器可读台账。
- 数据记录：`special-northern-song-960-kaifeng-center`，有效年份 960，`control-centers`、`evidenceLevel: D`、`reviewStatus: source-checked`。
- 台账 `gap-song_northern-960-960` 保持 `leave-unfilled`，`sourceBoundaryIds` 为空。这个结论表示没有疆界几何，不妨碍显示有史料支持的中心点。
- 历史审核：建宋与回师开封由《宋史》卷一支持；宋初政权关系由《续资治通鉴长编》卷一支持。没有将979年统一后的轮廓回填到960年。
- 制图审核：仅新增一个点，不绘面、不连接军事地点、不自动裁剪并存政权几何。陈桥兵变发生地与建宋后的都城点保持区分。
- 来源使用权：未复制参考地图几何或底图，只引用编年史并使用项目既有地点近似坐标。公开地图展示和数字文本再用条件仍需另行核对。
