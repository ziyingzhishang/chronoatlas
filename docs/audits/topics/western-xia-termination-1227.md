# 西夏终止年疆域复核（1227）

## 结论

1227 年西夏疆域几何留空。蒙古军围攻中兴府，末帝李睍投降后被杀，西夏独立政权终止。地图以低精度区域点单独标记终局事件位置；该点不表示年度政治中心、围城范围或全年疆界，也不回填1226年轮廓。
