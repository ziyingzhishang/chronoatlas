# 南宋南渡期疆域复核（1127—1138）

## 结论

1127—1138 年南宋疆界几何继续留空。地图逐年显示有史料支持的朝廷驻跸中心或迁徙路线节点，均以 D 级控制中心参照表达；点位不表示城址范围或全年连续实控。宋金军事对峙、南渡迁驻与行在建设均不足以推导同期完整疆界。

高桥弘臣对《建炎以来系年要录》《宋会要辑稿》等资料的研究梳理了1127年应天即位、十月迁扬州，1129—1130年高宗在江南各地辗转，1132年迁居临安，以及1134—1138年间为军事行动驻跸平江、建康并在1138年返回临安的阶段。朱溢发表于《复旦学报》的研究进一步给出驻跸区间：绍兴四年九月至五年二月（1134—1135）在平江，绍兴六年九月至八年二月（1136—1138）在建康，1138年二月后长驻临安；并据《建炎以来系年要录》核对1131年十一月筹备移跸和1132年正月抵临安。路线中的海上航段不绘点，不将城市点连为迁徙线。

## 记录与审核边界

- 历史来源审核：已核对高桥弘臣文章和复旦大学文史研究院提供的论文原文；按论文所引传统纪年逐段映射到项目公历年度。多点只表达同一年内先后驻跸，不表达停留时长或同时驻留；地图几何仍仅为 D 级城市参照点。
- 数据记录：`special-southern-song-{year}-court-centers`，逐年有效，`control-centers`、`evidenceLevel: D`、`reviewStatus: source-checked`。
- 台账 `gap-song_south-1127-1138` 保持 `leave-unfilled`，`sourceBoundaryIds` 为空。D 级中心参照和边界几何是两种不同结论。
- 历史审核：路线与驻跸节点可由研究引用的编年史及学术研究交叉支持。多点只列同一年有来源的先后节点；年度数据无法表达日级停留时长，因此不宣称点位覆盖全部临时行在或迁徙路径。
- 制图审核：只显示点，不绘控制区、边线或迁徙线。宋与金处于战争对峙；没有可审核的宋金共时疆界几何，本轮不自动裁切或拼接双方空间。
- 来源使用权：没有复制论文中的地图、表格或底图；点位使用近似现代城市中心。公开地图展示和来源文本再用条件仍需单独审核。
