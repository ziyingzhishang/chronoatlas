# 南唐937—959年长缺口专题复核（2026-10-21）

## 结论

- 缺口：937—959年，共23个民用年。
- 关键转折：杨吴禅代与南唐建国、939年改国号、闽地战争、楚亡、后周南征、958年割地称臣，以及959年后周末期再转折。
- 逐年结论：23/23年完成核对并明确留空；没有新增边界面，也没有使用960年最大轮廓桥接。
- 表达原则：区分节度辖区、战争占领、奉正朔/臣属关系和稳定直接控制，不把名义秩序绘成连续国界。

## 阶段核验

- 937年—939年，杨吴禅代、南唐建国与改国号：937年政权更替、建国与金陵建都，939年改国号为唐；年内身份转换不适合用960年轮廓回填。
- 940年—944年，烈祖后期与江淮整合：南唐经营江淮、地方节度和邻国关系仍在调整，行政沿革记录不能直接生成全境边界。
- 945年—947年，南唐介入闽地与区域战争：闽亡及相关军事行动造成控制范围变化，战争占领、附属关系和稳定直辖区不能压成单一年度面。
- 948年—951年，中主时期与南方政权竞争：南唐、南汉、楚及后周等关系持续变化；951年楚亡进一步改变区域格局，不能使用后期最大轮廓。
- 952年—955年，内外整合与后周压力上升：地方军政体系、边境防务和中原压力并行，来源不足以重建逐年直接控制线。
- 956年—958年，后周南征与南唐割地称臣：后周进攻导致南唐重大收缩，958年去帝号、奉后周正朔等政治变化使名义与实际控制不一致。
- 959年—959年，后周末期的依附状态与再转折：959年后周政局变化临近宋代周，南唐的外交依附和江南实际控制不能用稳定单一疆域表达。
