# 夏代传统约年与二里头文化核心复核（前2070—前1600）

## 结论

- 台账：`gap-xia_early--2070--1600`（471年年度结论与来源已核对；疆域面继续留空）。

该台账段覆盖471个公历年，年度结论逐条保存在[机器可读年度台账](./xia-early-cultural-core-annual-2070-1600.json)中。前2070至前1751年共320年，不显示二里头点位；前1750至前1600年共151年，只显示二里头遗址附近D级文化核心参考点。471年均无可发布的夏王朝国界几何。

调整依据是二里头遗址的考古年代不能覆盖项目所采用的完整夏代传统断年。国家发展改革委资料将二里头遗址年代约定为距今3800年，并介绍夏王朝建立约200年后在二里头营建大型都邑；中国社会科学院科技考古综述给出遗址绝对年代约前1750—前1530年。两者支持对遗址地点和考古阶段作有限表达，不足以证明二里头文化在前2070年已经出现，也不能把考古遗址直接等同于夏王朝全部疆域。

## 逐年表达规则

- 前2070至前1751年：证据不支持二里头考古文化点位前推，年度地图表达为 `leave-unfilled`。
- 前1750至前1600年：逐年显示同一个近似文化核心点，年度表达为 `cultural-core-point`；每年都明确不表示夏王朝直接控制、国界或完整文化分布。
- 所有年份：`directBoundary` 为 `null`；不使用公元0年，不从相邻朝代或传统夏代范围推导疆域。

年度台账每年记录来源 ID、地图表达和独立的 `evidenceGap` 说明：前320年说明现有考古年代不支持前推二里头文化点；后151年说明遗址文化核心不能推出夏王朝疆域。回归测试逐年检查这471个年份中320年无二里头点、151年仅有D级文化核心点，且没有确定疆界。
