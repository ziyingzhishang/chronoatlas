# 394 年并存政权来源轮廓复核

逐对来源记录、检测方法与运行时处置见[机器可读审核记录](./coeval-boundary-overlaps-394.json)。

## 发现与处理

- 对照 394 年有效的九个 Cliopatria v0.2.1 来源轮廓，采用严格内点检查、来源边界采样和严格线段交叉检查；未检测到多边形内部面积重叠。
- 早期扫描把部分边界接触误计为内部重叠。修正后撤销这九个轮廓仅在 394 年的误拦截；来源几何和有效时段保持原样。
- 这一结果只排除了本次几何筛查发现的面积相交，不证明这些低置信度时段轮廓是准确的年度历史疆界。其历史适用性、控制性质和发布条件仍需分别审核。
- 前秦 394 年继续不显示疆域面；马嵬事件点及其他独立点位不受轮廓复核影响。

## 复核限制

- 几何筛查不能判断历史控制范围或重建权威边界。
- 未检测到相交不能代替各来源轮廓的历史审核、制图审核、来源权利或公开地图条件核查。
- 原始来源几何不裁切、不拆分、不转归。
