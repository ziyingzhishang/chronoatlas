# 元1271—1293年疆域缺口逐年校勘（2026-11-02）

## 结论

- 范围：1271—1293年，共23个有效公历年；按至元八年至三十年本纪逐年记录。
- 地图表达：只增加大都、上都的D级低置信度政治中心参照点；不绘疆域多边形，覆盖范围台账的 `sourceBoundaryIds` 仍为空。
- 证据判断：本纪能支持年度政令、战事、受降、行政建置及外交往来，不能提供本段逐年连续的直接控制边缘。军事占领、行省设置、朝贡或属国关系、蒙古诸王势力均不自动等于直接疆界。
- 逐年机读记录：`docs/audits/topics/yuan-state-transition-1271-1293.json`。本段不以1352年轮廓或邻年最大疆域回填。

## 本轮来源复核（source-checked）

1271—1293年23条记录按《元史》卷7—17世祖本纪逐年核对；本轮抽核卷7、卷17在线文本和纪年范围，公历换算仍以各年本纪年号为准。大都新城始建于1267年，1272年正式定名；1271年仅保留上都中心参照。国家民委元代概述页面本轮无法访问，记作链接维护事项，不据该页面独立判定疆界。

地图仍只显示大都、上都政治中心点（大都点自1272年起），未形成年度疆界几何，coverage决策的 `sourceBoundaryIds` 为空。军事行动、受降、属国关系、行省设置和汗廷活动不作为直接疆界；本纪数字文本许可、地图资料使用权和公开展示条件分别审核。
