# 元1271—1293年长缺口专题复核（2026-10-21）

## 结论

- 缺口：1271—1293年，共23个民用年。
- 关键转折：1271年改国号、1276—1279年南宋核心区域接管与覆亡、1280—1281年统一后整合和对日战争，以及1282—1293年的行政与边疆重组。
- 逐年结论：23/23年完成核对并明确留空；没有新增边界面，也没有使用1352年最大轮廓桥接。
- 表达原则：区分名义疆域、行省/军政建置、属国关系、战争控制和稳定直接行政控制，不把它们自动合并为连续国界。

## 阶段核验

- 1271年—1275年，建国号与南宋战争延续：1271年改国号为大元，但南宋战争、蒙古诸王和各地旧政权关系仍在变化，不能用后期统一轮廓回填。
- 1276年—1279年，临安受降至南宋覆亡：南宋核心区域的接管、残余政权和战事持续至1279年；名义建国与实际控制转换不同步。
- 1280年—1281年，统一后整合与对日战争：全国统合、行省建置和海外军事行动并行，控制强度和行政覆盖不等于稳定边界。
- 1282年—1287年，内乱、行政整合与地方重组：中央权力、行省和地方反抗关系持续调整；以成熟期最大面覆盖会掩盖逐年变化。
- 1288年—1293年，边疆军事行动与行省化加深：北方、西北及东北边疆的军政建置和部族关系仍有差异；行政名义、军镇和实际控制不能压成一条年度边界。
