# 西秦复立与度坚山迁都复核（409）

## 逐年结论

409年不是全年连续独立统治的静态断面。年初乞伏乾归仍在后秦控制关系下；二月乞伏炽磐攻取枹罕，四月乾归抵达枹罕、收集部众二万人并迁都度坚山，七月才复即秦王位。年末独立西秦已经重建，但史料不足以据此复原全年稳定边界。

机器可读的年度结论、史料来源及缺口见[逐年台账](./western-qin-restoration-409.json)。

## 地图处理

- 409年继续不绘疆域面：攻取枹罕是军事节点，不能单独证明全年行政控制边缘；收集部众与复位也不能推出连续疆界。
- 本年不显示年度疆域面或全年政治中心。复立事件单独显示在白银—景泰—靖远交界宋家梁区域的低置信度参照点；地方志地望和现代宋梁地名坐标都不足以指认度坚山遗址，事件点不代表全年中心。
- 410年复都苑川、412年迁枹罕等后续中心分别处理，不回填到409年。

## 史料与限制

- 《资治通鉴》卷一百一十五按月份记录409年二月炽磐攻枹罕、四月乾归到枹罕后徙都度坚山、七月复即秦王位。该书支持过程次序，不给出度坚山精确坐标或逐年疆界。[《资治通鉴》卷一百一十五](https://zh.wikisource.org/zh-hans/資治通鑑/卷115)
- 《资治通鉴》卷一百一十六记410年攻取后秦郡县、八月复都苑川，说明409年中心不能用410年后苑川点回填。[《资治通鉴》卷一百一十六](https://zh.wikisource.org/zh-hans/資治通鑑/卷116)
- 《中国民族史》将度坚山比定为今靖远县西，可作区域考证；该区域判断不足以生成精确城址点或边界。[《中国民族史》相关章节](https://szzy.7lue.cn/read/5635ed7e662cffd3f7946e6453f91d82/0cd2e83abe6d001dd868e2b470e136c6.md)
- 《白银区志》进一步将度坚山定位于白银区、景泰县与靖远县交界的宋家梁一带；现代宋梁点位只用作宽泛事件区域参照，点位来源及公开使用条件仍需单独复核。[《白银区志》](https://www.gsdfszw.org.cn/gsxz/bys_269/byq/201708/P020171012594776724580.pdf)；[宋梁现代地名坐标](https://www.fallingrain.com/world/CH/15/Songliang.html)
