# 后唐建政初期疆域缺口复核（923—925）

逐年结论数据：[后唐 923—925 年](later-tang-founding-923-925.json)。

## 逐年判断

| 年份 | 史料支持的结论 | 空间判断 |
| --- | --- | --- |
| 923 | 李存勖在魏州称帝建后唐，随后军队攻入开封，后梁终止；称帝地、后唐迁入洛阳后的中央中心及后梁终局并非同一节点。 | 显示魏州即位区域事件点与后唐迁入洛阳后的政治中心参照；魏州、开封与后梁旧地不据事件地点连成后唐疆域。 |
| 924 | 后唐中央政治中心继续在洛阳，政权处理建立后的军政事务。 | 只保留洛阳点；不把923年军事胜利视作全境稳定归附。 |
| 925 | 后唐军队攻蜀，成都陷落，前蜀中央政权终止。 | 成都点作为前蜀终止事件地点，不作为后唐年内已稳定直辖巴蜀的证明。 |

## 处理结论

- `gap-tang_later-923-925` 维持 `leave-unfilled`，923—925年均不生成疆域面。
- 增加后唐迁入洛阳后的D级政治中心点；它不代表923年初或魏州称帝地点。
- 为923年魏州即位补充低置信度区域事件点。点位参考CHGIS魏州治贵乡县记录（其有效时段为621—626年），只作县域级近似定位，不表示923年即位坛址或准确城址；魏州地点与洛阳后续中心分别显示。
- 923年后梁终止与后唐建政、925年前蜀终止分别记录；军事占领、年内交接和地方行政接收不混写为同一疆界。
- 不以925年后唐控制巴蜀或后续轮廓倒填923—924年；不自动裁切后梁、前蜀等并存几何。

## 来源与审核

- 《资治通鉴》卷272《后唐纪一》核对923年称帝、后梁战争与开封终局；卷273核对924年；卷274《后唐纪三》核对925年攻蜀、成都陷落和王衍出降。
- 洛阳采用 `src/data/places.ts#luoyang` 的近似城市点。史料支持后唐迁入洛阳后的中央中心，但不能据此推定后唐完整疆域。
- 魏州依据《资治通鉴》卷272“筑坛于魏州牙城之南”定位事件；空间参照使用[CHGIS魏州记录](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_87763)，该条坐标记录的是621—626年魏州治贵乡县、不是923年的即位坛址。数据库标注CC BY-NC 4.0，授权和公开展示条件需另行核对。
- 925年前蜀终止事件原先误引卷272，现已更正为卷274；各来源的使用权与公开地图条件另行核查。
