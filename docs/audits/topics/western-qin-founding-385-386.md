# 西秦初建疆域复核（385—386）

## 结论

385—386年逐年显示勇士城的低置信度区域中心参照，疆域面继续留空。385年《晋书》系年记乞伏国仁在九月建政、筑勇士城；这条都城记录只对应公历年的后段。386年延续勇士城阶段。金城是后续中心：乞伏国仁于388年去世后，乞伏乾归继位并迁金城，不应把金城点位提前覆盖本段。

逐年结论、部分年份的适用时段和证据缺口见[机器可读台账](./western-qin-founding-385-386.json)。

## 史料与地点精度

- 《晋书》卷一百二十五记太元十年乞伏国仁建政、置十二郡并“筑勇士城以居之”；同卷记太元十三年国仁去世，乞伏乾归继位后迁金城。《资治通鉴》卷一百六交叉记录西秦成立节点。[《晋书》卷一百二十五](https://zh.wikisource.org/zh-hans/晉書/卷125)；[《资治通鉴》卷一百六](https://zh.wikisource.org/zh-hans/資治通鑑/卷106)
- 《榆中县志》把勇士城故城考在榆中县东北夏官营一带；当地古城遗址与勇士城具体对应仍有不同考证。项目仅用夏官营镇中心作区域级近似参照，置信度为低，不宣称精确城址。[《榆中县志》](https://www.gsdfszw.org.cn/gsxz/lzs_266/yzx/201708/P020170814560773151422.pdf)
- 乞伏部众归附、军队征伐、秦河二州牧名义和后来更广的疆域描述分别属于政治、军事或名义关系证据，不能据此绘制385—386年的连续实控边界。

## 审核与发布

- 历史来源审核：已核对《晋书》卷125、《资治通鉴》卷106及《榆中县志》相关记载，逐年结论和证据边界已登记在机器可读台账中。
- 历史审核：将385年九月建政、勇士城阶段与388年继位迁金城分开，避免年度点位错置。
- 制图审核：385年点仅说明年后段勇士城中心，386年点作区域参照；无疆域面，不由后续断面回填。
- 位置精度：夏官营坐标代表现代镇级区域中心，不代表考古遗址坐标。勇士城古址进一步考证前，不提升为高精度地点。
- 来源使用权与公开展示条件须独立核对；史料和县志位置考证不等于获准复制地图图件。
