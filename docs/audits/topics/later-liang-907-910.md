# 后梁建立初期疆域复核（907—910）

逐年结论数据：[后梁 907—910 年](later-liang-907-910.json)。

## 结论

907—910 年均不绘制后梁疆域面。根据编年史记录的首都阶段，地图主要中心点为：907—908 年大梁（汴州／开封府），909—910 年洛阳。909 年正月后梁迁都洛阳，任大梁为东都留守；《通鉴》同年秋季又记皇帝还大梁。现将迁都与返都分别列为城市事件点，年图同时保留洛阳主都和大梁东都点；这不表示迁行路线或固定驻跸。现有坐标是今开封、洛阳的城市近似点，不代表五代城垣范围。

## 同断面并存政权与缺口

史料在 907—910 年提及吴、吴越、马楚、前蜀、闽、岐、河东晋、幽州刘氏等不同政权或藩镇。当前项目对同一时期的吴越、马楚、前蜀等条目也保留疆域空缺；运行时没有可与本段相交的已审核边界面，所以本轮没有执行几何裁剪，也不把留空解释为这些政权不存在。当前目录未将李克用／李存勖的河东晋政权作为独立政权建模，应登记为台账外缺口，另行排序，不将其与五代后晋混为一体。
