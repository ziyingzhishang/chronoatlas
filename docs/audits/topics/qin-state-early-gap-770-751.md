# 秦国早期疆域复核（前770—前751）

## 结论

- 台账：`gap-qin_state--770--751`（20年结论与来源已核对；逐年显示都邑中心参照，控制边界均留空）。

这20个公历年的疆域面继续留空。史料支持秦国政治存在、前770年传统受封节点及其早期军事活动，但“岐以西”的封授叙事、戎秦攻守、早期都邑迁徙和遗址分布不足以给出每年连续、可审核的实控边界。本条不把名义封地或文化活动范围画成确定疆界。

地图可显示两处低置信度都邑区域中心参照：前770—前763年为西犬丘（今礼县区域），前762—前751年为汧渭之会（今宝鸡陈仓区魏家崖周边）。20条年度结论都标为 `capital-center-point`，并逐年绑定中心点和来源；其城市级坐标不等于古城遗址测绘点、城垣或秦国疆界。魏家崖作为汧渭之会的考古比定有近年联合考古支持；西犬丘与礼县西山等遗址的精确对应仍有讨论。[早期秦都邑考古综述](https://story.gscn.com.cn/system/2024/02/21/013100545.shtml)；[西北大学文化遗产学院：魏家崖与汧渭之会](https://culture.nwu.edu.cn/info/1135/3635.htm)

逐年结论、证据缺口和来源列于[机器可读年度台账](./qin-state-early-gap-770-751.json)。每年单独记录，不由邻年轮廓回填。

## 史料与空间边界

- 《史记·秦本纪》记秦襄公护送周平王东迁后受封为诸侯，称“赐以岐以西之地”，并记其后秦与戎的冲突。它支持秦国地位、事件和传统封授叙述，但“赐地”并不能证明相关地区在前770年已被秦逐地稳定控制，也没有给出可定位的边线。[《秦本纪》](https://zh.wikisource.org/zh-hans/史記/卷005)
- 甘肃文物考古研究的公开综述将早期秦活动中心联系到礼县西犬丘一带，并指出秦文公东进、在汧渭之会营建城邑，随后秦宪公时期迁往平阳；陕西地方志材料也记录“岐以西”以及犬戎占据岐丰的背景。这些线索显示活动中心与实际控制逐步变化，不能用后代秦国或战国疆域图反推本段边界。[甘肃文旅所载考古综述](https://www.gswbj.gov.cn/a/2021/06/18/9746.html)；[陕西地方志资料](https://dfz.shaanxi.gov.cn/zslm/fzzlk/xbsxsz/szdylpdf/201404/P020240923616206405975.pdf)

此前把秦国早期“雍”都以长安坐标表达的记录不准确，现已按西犬丘、汧渭之会、平阳、雍城、栎阳、咸阳阶段拆分中心参照，并在年度台账中只为本次复核的20年记录前两段。疆域台账结论仍是 `leave-unfilled`，不以中心点替代疆域结论。
