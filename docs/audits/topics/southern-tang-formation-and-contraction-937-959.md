# 南唐形成与收缩：937—959 年逐年审计

范围：`gap-southern_tang-937-959`，共23个公历年。

## 来源复核（source-checked）

《资治通鉴》卷281—294按年核对南唐建国、君主更替、灭闽灭楚、后周南征及958年割地称臣等节点；本轮抽核卷281、283、284、292、294在线文本与卷目。《宋史》卷478作为后出纪传材料交叉校验李氏世系、迁豫章、割地及政权覆亡。龙南市政府《历史沿革表》记载937—953年南唐虔州昭信军节度沿革，只用于赣南局部行政史，不推及南唐全境。韩国国史编纂委员会综述作为五代阶段背景。

南京市地方志办公室南唐都城 PDF 因文件体积过大未能在线解析，列为来源版本和原文页码复核事项；本审计未从该 PDF 提取地图。

## 空间判定

937—959年23条逐年结论均以D级、低置信度城市点表示金陵／建康政治中心，疆界面均留空。割地称臣、军事战线、藩镇设置、地方归附及单一区域沿革不能合成全年连续直接控制边界。相邻 Cliopatria record 3842 的来源时段始于960年、置信度低且控制性质未定；不向前回填到937—959年。来源使用权与公开地图条件另行审核。


## 闽亡与福州战事空间复核

《资治通鉴》卷285记945年南唐攻克建州、王延政降；汀、泉、漳随后分别降唐。946年另记南唐攻下福州外城。故945年终止事件点落在建州治所区域，946年福州事件点只表达外城战事。CHGIS建州时间地名录记建州治所在建安县（今建瓯），并记943年王延政以建州为殷国都；都城沿革按943年由福州转至建州记录。两处城市点均不表示全闽边界或稳定直辖范围。CHGIS标注CC BY-NC 4.0，本项目未复制其几何，公开或商业使用另行审核。
