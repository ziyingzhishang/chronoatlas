# 北元1440—1467年长缺口专题复核（2026-10-21）

## 结论

- 缺口：1440—1467年，共28个民用年。
- 关键转折：也先势力扩张、明蒙战争、1449年土木之变、也先与脱脱不花并立、1454年也先被杀及其后瓦剌/鞑靼分立。
- 逐年结论：28/28年完成核对并明确留空；没有新增边界面，也没有使用1519年最大轮廓桥接。
- 表达原则：区分元室汗统、瓦剌军事权力、东蒙古部众、明方防御线和实际直接控制，不以“北元”标签覆盖所有蒙古势力。

## 阶段核验

- 1440年—1443年，也先势力扩张与蒙古诸部整合：瓦剌、鞑靼及东蒙古诸部关系持续调整，联盟和军事控制不能压成统一年度边界。
- 1444年—1448年，明蒙战争与北方边疆重组：明方边防、蒙古诸部和贸易使团关系变化频繁；明朝防御设施不等于北元控制线。
- 1449年—1449年，土木之变与政治重构：年内发生战争、皇帝被俘和权力重组，不能使用前后任一稳定轮廓代表全年。
- 1450年—1453年，也先与脱脱不花并立：汗权、瓦剌军事权力和东蒙古部众之间存在竞争，名义汗统与实际控制需分开。
- 1454年—1454年，也先被杀与分裂：也先死后政权迅速分化，单一“北元”面无法表达年内转折。
- 1455年—1467年，瓦剌与鞑靼等势力分立：后续部族联盟和汗统不断变化，现有1519年北元轮廓不能向前外推。
