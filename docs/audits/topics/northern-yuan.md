## 本轮来源复核（source-checked）

韩国国史编纂委员会《朝鲜初期的对外关系·北方民族的蠢动》已按原文核对脱欢死后也先继承、1448年前后的东西扩展、1449年入明与土木之变、1450年送还英宗、1454年汗权斗争与蒙古分裂。原文也说明也先势力影响范围广，但这些叙述不足以确定每个公历年的稳定直接控制边缘，故28年均留空。

来源清查发现，原年度行里的中国国家博物馆页面实际介绍1387年明代巡牌，年代不适用于1440—1467，现已从年度来源 ID 移除。《明实录·英宗实录》维基文库页面当前为序文，链接的中研院史料库本轮无法读取，暂不作为已核年度来源；后续取得可访问正文后再交叉核对。未复制或绘制任何影响范围、军事实力或邻年几何。
