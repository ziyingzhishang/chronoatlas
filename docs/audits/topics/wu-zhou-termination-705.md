# 武周终止年度复核（705）

## 结论

- 台账：`gap-wu_zhou-705-705`（同年政权转换时序已核对；疆域面继续留空）。

705年疆域面继续留空，但年度结论补充了明确的政权转换节点和洛阳城市参照。神龙元年正月发生神龙政变，武则天传位、唐中宗即位；二月初四恢复唐国号，神都恢复东都称谓。洛阳在转换前后仍是朝廷所在城市，因此可作为城市级参照；公历年粒度不能把武周在年初的政权状态代表为全年疆域。

逐年机器可读记录见[年度台账](./wu-zhou-termination-705.json)。它保留本年唯一有效公历年、中心表达、来源和疆域留空理由。

## 唐来源面交接年拦截

运行时几何核对发现，唐 Cliopatria record 2642 的近似时段为705—749年，从705年起渲染为唐的多边形；该公历年二月已恢复唐国号，年值无法表达武周与唐之间的具体交接时点。该来源置信度低、控制性质未明，不能作为唐的稳定全年直接控制边界。现登记 `conflict:wu-zhou-tang-transition:705`，仅在705年将原几何挂待审并从运行时暂扣；保留完整来源几何，不裁切、不转归，706年从原区间恢复。洛阳城市参照及武周、唐的转换标题仍保留。来源使用权与公开展示审核独立处理。

## 史料与范围判定

- 《资治通鉴》卷二百七记神龙元年正月的宫廷政变、太子监国和武则天传位；卷二百八接记二月初四恢复唐国号，并将神都恢复为东都旧称。[卷二百七](https://zh.wikisource.org/zh-hans/資治通鑑/卷207)；[卷二百八](https://zh.wikisource.org/zh-hans/資治通鑑/卷208)
- 陕西师范大学有关武周都城的讲座梳理了洛阳在武周时期作为都城，以及复唐后长安与洛阳的双都关系；此类都城研究可支持城市级中心背景，不提供705年逐月实控疆界。[陕西师范大学讲座](https://www.snu.edu.cn/info/1016/2855.htm)
- 705年年初的武周政权与年内复唐属于同一公历年内先后发生的政权状态。项目不把年内某一日的边界外推至全年，也不将唐的后续疆域自动视为武周边界。

## 审核与发布

- 历史审核：按卷207、卷208分别记录政变、传位与复唐节点，不把705年简单当作全年武周或全年唐。
- 制图审核：只保留洛阳城市级中心参照，不关联武周疆域几何；地图不从前一年轮廓回填。
- 来源使用权、地图数据许可和公开展示条件仍需分别审核；引用史料和讲座不代表取得地图图件的复制权。
