# 西凉建立与早期政治中心：400—406 年

## 审计结论

覆盖台账 `gap-western_liang-400-406` 的七个有效公历年。400—404 年显示敦煌城市级政治中心点，405—406 年显示迁治后的酒泉点。所有年度的 `territoryBoundary` 均为空：现有文字史料足以支持中心和部分行政归属变化，但不提供可逐年复原的连续直接控制边界。
