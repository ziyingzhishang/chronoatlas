# 前秦终止：394年

结构化年度结论见[former-qin-termination-394.json](./former-qin-termination-394.json)，用于校验四月、七月、十月的事件次序及地图留空决定。

## 逐年结论与时序

394年，前秦苻登在据点和战场之间移动，不能用长安一个城市点表示全年中枢，也没有足够依据绘制全年疆域面。

| 时段 | 史料结论 | 空间表达 |
|---|---|---|
| 年初 | 姚苌去世后，苻登从胡空堡出兵东进，并留苻广守雍、苻崇守胡空堡。 | 不落中心点；不表示全境仍被同一政权稳定控制。 |
| 四月 | 苻登攻废桥，在马嵬受挫，单骑奔雍，后又收集余众、进入马毛山。 | 增加今兴平马嵬区域级战事事件点；不定位古堡或阵地，也不是年度中心。雍、平凉、马毛山是后续移动据点。 |
| 七月 | 苻登出兵迎接西秦援军，在山南被姚兴擒获并杀死；苻崇继位。 | 终止事件不落在长安，也不以马嵬代替山南。 |
| 十月 | 苻崇与杨定攻西秦失败，二人俱亡，前秦后期政治结构终止。 | 无经核坐标的单点，疆域留空。 |

## 修正的原记录

- 《资治通鉴》卷一〇八（[维基文库](https://zh.wikisource.org/zh-hans/資治通鑑/卷108)）按春、夏四月、秋七月、冬十月记载苻登东进、败退及两次政权终止；明确区分马嵬败退与山南被擒杀。
- 《晋书》卷一一五·苻登载记（[维基文库](https://zh.wikisource.org/zh-hans/晉書/卷115)）记苻登据胡空堡、雍、平凉等处往返。原长安都城时期曾延至394年，现改为351—385年；386—394不以长安作为统一地点。
- 《兴平县志》（[陕西省地方志办公室 PDF](https://dfz.shaanxi.gov.cn/zslm/fzzlk/xbsxsxz/xbsxsxz/xys_16200/201405/P020240923610153985830.pdf)）将马嵬镇记为县西部重镇，并载政府驻地距县城12.5公里；志中沿引旧志、长安志及里程考说对马嵬店、马嵬坡距县城有异。此资料补充旧兴平县西部的地望，但未给394年具体战场坐标、古堡界线或战线，区域事件点仍为低置信度参照。
- 政权终止事件移除长安地点标记。长安作为城市遗产与后秦承接继续记录，但不冒充苻登394年末期中心。
