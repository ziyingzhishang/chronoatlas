# 南凉终结年疆域复核（414）

## 逐年结论

414年南凉以乐都为阶段性政治中心；西秦于年内攻取乐都，设置守将并迁徙南凉王族及官民，秃发傉檀随后归降。地图可以显示乐都这个年内中心点，但必须把它理解为南凉覆亡前的阶段，而不能读成南凉在整个公历年继续独立统治。南凉疆域面留空。

机器可读的逐年结论、来源和缺口见[逐年台账](./southern-liang-termination-414.json)。

## 并存政权与地图表达

- 年内西秦在枹罕保持政治中心，南凉在失守前仍以乐都为都城；地图并列显示两个城市中心，表达年内政权交接过程。
- 乐都和枹罕都是中心点，不绘相互重叠的疆域面。军事攻城、俘迁和归降分别记录，不把事件路线或城池占取等同于完整领土边界。
- 西秦来源几何 `clio-1684-western_qin-414` 的原始时段为414—416年，与南凉414年年内易手产生并存冲突；冲突标记为待审。414年运行地图暂不显示该来源面，原始几何和414—416年来源时段保持不变，不做自动裁剪；415年仍按来源时段显示，待后续历史与制图审核。
- 乐都点采用现代乐都区中心作城市级参照，不表示南凉古城墙范围或考古遗址边界。

## 史料与审核

- 历史来源审核：年内攻城、迁徙与归降依据《资治通鉴》卷116、《晋书》卷126及地方志记录；逐年用途和边界限制已写入机器可读台账。
- 《资治通鉴》卷一百一十六记南凉傉檀出征乙弗，西秦趁机袭乐都，城陷后任命守将、迁徙虎台及文武百姓万余户；随后傉檀归降。[《资治通鉴》卷一百一十六](https://zh.wikisource.org/zh-hans/資治通鑑/卷116)
- 《晋书》卷一百二十六记秃发氏后期政权与归降背景；临夏地方志将乐都失守系于义熙十年（414）五月。[《晋书》卷一百二十六](https://zh.wikisource.org/zh-hans/晉書/卷126)、[《临夏州志》相关卷](https://www.gsdfszw.org.cn/gsxz/lxhzzzz_278/lxx/201708/P020171013398698926147.pdf)

- 制图审核：显示南凉乐都和西秦枹罕两个中心点，不使用南凉疆域面；地图输出测试确认没有以点代边界。
