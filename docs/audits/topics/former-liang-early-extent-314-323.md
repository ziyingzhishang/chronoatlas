# 前凉早期疆域复核（314—323）

## 结论

- 台账：`gap-former_liang-314-323`（10年史事与来源已核对；控制边界继续留空）。

十年均以姑臧显示城市级政治中心，疆域面继续留空。张氏前期奉晋朝名号和职官治理凉州；320年张寔遇害后，张茂接掌河西政务；322年向陇西、南安扩展、设置秦州并令韩璞镇冀城；323年刘曜围陇城、遣刘咸攻冀城并沿河施压，张茂随后称藩。地图在322年为秦州设治节点、323年为两处战事各增加区域事件点，位置均只作今甘谷境内和张家川一带的低置信度现代区域参照，不定位古城或战场，不表示疆界。名义臣属、地方行政、军事扩展和称藩关系分别记录，不把它们混画为前凉或前赵直接疆域。

## 史料与空间判定

- 《晋书》卷八十六《张轨传》及张寔、张茂传记载张轨在姑臧经营河西、张寔由州人推为摄父位并获晋廷授官、张茂接掌后继续奉晋臣名义；其后记张茂派军取陇西、南安并置秦州，称驻冀城者为韩璞。《甘谷县志》同年条称韩瑶，是姓名异文；本审核按正史采用韩璞，县志仅用于冀城的区域地望参照。该传记支持中心和关键行政、军事转折，但没有给出314—323每年的边界线。[《晋书》卷八十六](https://zh.wikisource.org/zh-hant/晉書/卷086)
- 《资治通鉴》卷九十二具体记刘曜围陇城、遣刘咸攻驻冀城的韩璞、呼延晏攻桑壁，并记张茂沿河诸戍溃散及其后称藩。攻城和驻军崩溃说明323年边防压力，但不证明前赵当年全面接收河西。[《资治通鉴》卷九十二](https://zh.wikisource.org/zh-hans/資治通鑑/卷092)
- 《天水市志》将陇城约束到今张家川一带；《甘谷县志》记冀城在今甘谷境内。两处仅用于区域参照点，不确定具体古城遗址或战场。[《天水市志》](https://www.tianshui.gov.cn/virtual_attach_file.vsb?afc=Ko77ObL8UsoR7anxmfkn77PMl7sL4lJDoRvbMmUaLNV2UNC0gihFp2hmCIa062TApjMw6ITjpsC0C5n8CIMwg4G0QDVJQsrZqIVJLR-Jv2nto4OeoDnt_tWjvYhXptQ0g47sMmL0LzCsLSbw6208c)、[《甘谷县志》](https://www.gsdfszw.org.cn/gsxz/tss_270/ggx/201708/P020171123335863157442.pdf)
