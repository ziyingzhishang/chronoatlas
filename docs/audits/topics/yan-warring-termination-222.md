# 燕终结年疆域审计：前222年

- 台账：`gap-yan_warring--222--222`（疆域继续留空；增加低置信度政治中心区域参照）
- 年度记录：[`yan-warring-termination-222.json`](./yan-warring-termination-222.json)
- 年份：前222年，秦始皇二十五年
- 史事：燕王喜与太子丹此前在秦军攻取蓟后东保辽东；秦始皇二十五年，王贲攻辽东并俘燕王喜，燕国最后政权终结。[《资治通鉴》卷七](https://zh.wikisource.org/wiki/資治通鑑/卷007)与[《史记·秦始皇本纪》](https://ctext.org/shiji/first-emperor-of-qin/zhs)均可核对前222年的攻辽东与俘王记录。薛兰霞、杨玉生2011年《论燕国的五座都城》进一步将辽阳列为燕最后都城，称燕王喜在失蓟后迁至辽阳、五年后被俘；这是一项学术研究结论，燕都迁徙年代和地点仍有分歧。
- 地图表达：前222年只显示今辽阳市城区的低置信度区域政治中心参照点，不标蓟为本年中心，也不绘制燕国面。点位是现代城市区域级定位，不指认战国襄平具体城址或城垣。
- 空间证据缺口：辽阳最后都城的研究可支持区域中心参照，但《通鉴》仅明确记燕王东保辽东，未点名辽阳；现有资料仍不足以复原前222年全年直接控制边界。“辽东”地区名不能直接转成燕国边界。
- 数据：年度记录使用 `control-center-point` / `liaoyang`；地点资料、燕都阶段和D级点位共用来源 `yan-capital-relocation-liaoyang-2011`。燕都阶段蓟截至前227年，辽阳区域参照为前226—前222年。
- 审核：中心点属于研究性低置信度区域表达，不等同疆域边界；独立历史审核、制图审核、论文复用权与公开地图要求仍按项目发布流程单独核对。
