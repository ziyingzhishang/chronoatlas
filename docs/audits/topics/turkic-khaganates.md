# 突厥661—744年长缺口专题复核（2026-10-21）

## 结论

- 缺口：661—744年，共84个民用年。
- 政权身份：必须区分西突厥余部、唐朝羁縻体系、682年后突厥复兴，以及742—744年拔悉密、回纥、葛逻禄与突厥余众之间的多方交战和汗位更替，不能把“突厥”作为连续不变的单一边界实体。
- 逐年结论：84/84年完成核对；疆域边界全部留空，682—743年显示低精度于都斤政治核心区域参照点。没有新增边界面，也没有使用561—576年最大轮廓桥接。
- 直接控制与影响：战争、朝贡、臣属、碑铭叙事和文化影响不自动转换为直接控制边界。

## 阶段核验

- 661年—681年，西突厥崩解后至后突厥复兴前：661—681年处于西突厥余部、唐朝羁縻体系与草原部众重组期，不能把561—576年的第一突厥汗国轮廓延续到本段。
- 682年—691年，骨咄禄／颉跌利施可汗复兴：后突厥重新建立并争夺漠北控制；起兵、迁牙与部众归附持续变化，没有逐年可重发布边界。
- 692年—715年，默啜可汗时期：对唐、契丹、九姓铁勒等关系随战争与臣属变化，碑铭和编年可证明事件，不足以恢复每年直接控制线。
- 716年—716年，毗伽可汗即位与继承危机：汗位更迭和内部冲突发生于年内，不能用前后稳定时期的轮廓替代。
- 717年—731年，毗伽可汗与阙特勤时期：鄂尔浑碑铭和唐史可核对人物、战争与政治中心；影响圈、附属部落和直接统治区仍需分开，不能生成单一面。
- 732年—735年，阙特勤、毗伽可汗碑铭时期：732、735年碑铭是重要一手遗存，但纪念碑地点和文字叙事不是年度边界数据；现代译文版权亦不作为复制材料。
- 736年—743年，毗伽可汗后期至乌苏米施可汗：继承与部众关系恶化，后突厥控制范围持续收缩和分裂，不能用最大参考面覆盖。
- 742年—742年，突厥诸部权力分裂：拔悉密、回纥、葛逻禄攻杀骨咄叶护，突厥余众另立乌苏米施可汗；分别记录不同政治主体，不将联盟攻伐作为同一政权的统一疆界。
- 743年—743年，传世编年未记新的突厥汗位转换：《资治通鉴》卷215本年条目无突厥汗位更迭记载；此来源未载不能证明政局稳定或疆界不变。
- 744年—744年，乌苏被杀、白眉继立与回纥建汗：拔悉密杀乌苏后突厥余众立白眉；回纥、葛逻禄又杀拔悉密可汗，骨力裴罗自立并受唐册为怀仁可汗。直到745年《资治通鉴》才记回纥击杀白眉，故744年不概括为全年完成覆亡和统一接替。
