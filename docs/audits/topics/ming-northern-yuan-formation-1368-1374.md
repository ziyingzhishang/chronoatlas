# 明与北元形成：1368—1374 年逐年审计

范围：`gap-ming-1368-1374`、`gap-northern_yuan-1368-1374`，共14条政权—年度结论。

## 来源复核（source-checked）

《明太祖实录》与《元史》顺帝本纪用于逐年核对建国、北迁、上都—应昌—和林驻地变化及明军北征。台湾中研院明清研究资料提及1368—1372年黑水城文书中的北元文书，支持北元在政权退出中原后仍延续；Cambridge 考古研究提供和林城址与聚落格局依据。上述史料和研究可支持政权延续、驻地及中心点，不足以支持这七年双方的连续疆界。

## 空间判定

明、北元各年只显示可定位的政治中心；1369、1370年北元多点表示年内先后驻地，不连接为路线，也不视作同步控制区。14条记录没有疆界面，两条决策均保持 `leave-unfilled`。当前来源不足以按年确定两政权连续直接控制外缘；军事占领、汗廷迁移、军卫设置、羁縻关系及后世版图均不替代疆界证据。城市与遗址坐标仅作现代近似定位。来源使用权及公开地图条件另行审核。

逐年 `evidenceGap` 已按断面细化：1368年北元上都点不代表北撤路线或全年旧元疆域；1369年上都失守、转驻应昌是先后中心；1370年应昌陷落、顺帝去世与昭宗北走和林是年内不同阶段；1372年和林为汗廷中心，明军北征战场不作为控制边界。
