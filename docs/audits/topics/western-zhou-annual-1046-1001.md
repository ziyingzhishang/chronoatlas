# 西周早期逐年疆域复核（前1046—前1001）

## 空间结论

46个公历年均显示丰镐都邑区的低精度王室中心参照点；全部年份的疆域边界留空。丰、镐是沣河两岸的都邑群，点位不等同单一宫城、王畿范围、诸侯封国或王室直接控制边缘。逐年结构化来源、结论与证据缺口见 [年度JSON](./western-zhou-annual-1046-1001.json)。

## 纪年校勘

项目沿用常见传统年表，将西周建政和商周更替导航约置于前1046年。该绝对纪年不是唯一学术方案。Pengcheng Zhang 2023年《The Chronology of Western Zhou》依据西周青铜器铭文历日等资料，提出前1046年为周人初次伐商、前1044年为克商；其研究也讨论了《竹书纪年》《武成》《世俘》等记录之间的差别。此方案是具名研究重建，不作为无争议定论，也不改变项目沿用的传统导航约年。

| 公历年 | 年度结论 | 地图表达 |
| --- | --- | --- |
| 前1046 | 项目传统约年标记商周更替；另一研究将本年视为初次伐商。 | 丰镐王室中心参照；疆域未定；商代来源期段面因交替年控制时序未定而暂挂，不裁剪或转交。 |
| 前1045 | 在上述重建中处于初次伐商与克商行动之间；传统年表节点仍按项目原口径保留。 | 丰镐王室中心参照；疆域未定。 |
| 前1044 | 上述研究重建将本年定为克商年；项目仍采用前1046年传统王朝更替约年。 | 丰镐王室中心参照；疆域未定。 |
| 前1043—前1042 | 武王卒后周公摄政、管蔡之乱与东国秩序动荡。 | 丰镐王室中心参照；疆域未定。 |
| 前1041—前1036 | 成王时期东征与秩序重建。 | 丰镐王室中心参照；疆域未定。 |
| 前1035—前1021 | 成王后期分封秩序逐步形成。 | 丰镐王室中心参照；疆域未定。 |
| 前1020—前1001 | 康王早期；早期王年重建仍有研究争议。 | 丰镐王室中心参照；疆域未定。 |

这些历史阶段可以解释年度状态标题，但都不支持把王室活动、军事征服、分封或来服关系合并为年度连续边界。未用前1000年以后来源面回填本段。
