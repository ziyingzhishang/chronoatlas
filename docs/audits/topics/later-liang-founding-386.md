# 后凉初建中心复核（386）

## 逐年结论

《资治通鉴》将吕光入姑臧、自领凉州刺史记在太元十年（385）秋段；太元十一年（386）条记吕光继续据姑臧，张大豫兵进姑臧城外后被击败，吕光于十二月自称凉州牧、酒泉公。结合《武威市志》编年，386年作为后凉政权形成年度；地图显示姑臧城市中心点。现有材料不足以复原后凉初年稳定直接控制边界，因此疆域面留空，也不将后凉后期轮廓前推至建政年。

## 史料与表达

- 《资治通鉴》卷一百六把吕光入姑臧、自领凉州刺史列在太元十年（385）秋段；386年条记张大豫进屯姑臧城西、为吕光击败，吕光十二月自称凉州牧、酒泉公。《晋书》卷一百二十二记吕光据姑臧、以凉州为政治基础；《武威市志》以386年秋为建立后凉、都姑臧的编年节点。本审核因此区分385年取得姑臧与386年后凉政权名号、政治实体形成，不把两者压成同一时间点。[《晋书》卷一百二十二](https://zh.wikisource.org/zh-hans/晉書/卷122)、[《资治通鉴》卷一百六](https://zh.wikisource.org/zh-hans/資治通鑑/卷106)、[《武威市志》相关卷](https://www.gsdfszw.org.cn/gsxz/wws_271/mqx/201708/P020171013370237811404.pdf)
- 中心点表示姑臧城市位置参照，不表示城墙范围、后凉行政边界或386年全年控制区。
