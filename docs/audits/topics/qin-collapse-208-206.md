# 秦末（前208—前206）疆域缺口逐年复核

## 结论

- 对应台账：`gap-qin--208--206`，共 3 个公历年；史事与纪年来源已核对，疆界继续留空。
- 机器可校验的逐年结论、地图表达和证据缺口见 [`qin-collapse-208-206.json`](./qin-collapse-208-206.json)。
- 前208、前207年登记秦末朝廷的咸阳政治中心参照；前206年因年内秦亡、汉王入关及项羽入咸阳，年度地图留空秦中心点。不新增连续疆域面，`sourceBoundaryIds` 保持为空。
- 前207／前206的秦亡纪年在史料纪年、秦历／汉历转换及后世公历年表中存在口径差异。本项目按既有政权终年 `-206` 保留最后一年记录，并在该年说明子婴降汉和项羽入关是年内转折；不把这一点解释为秦在全年持续控制咸阳或关中。
- 前207年刘邦军入武关的史事可由《咸阳市志》年表核对，地点仅记为今丹凤县东南一带。学术与地方考察资料对秦、汉时期武关地望及现存遗址对应仍有不同观点；因此本批不新增武关事件坐标，避免把现代武关镇或某处遗址误作前207年精确关址。
- Lander 对秦帝国新征区的研究将约前230—前206年东部、南部征服区域作为累计空间，并指出这些区域控制较弱。[论文正文及图1说明](https://doi.org/10.1017/jch.2022.19)可作为秦末中央行政控制差异的区域背景；其累计范围不说明前208或前207年起义后各县归属，不据此绘制秦末边界。
- 该 D 级点位是可定位的都城中心替代表达，不能代替三秦、汉王或西楚后续边界。尚无足够逐年直接控制空间证据，疆域结论继续留空。

## 逐年结论

| 公历年 | 政权与军事变化 | 空间表达 |
| ---: | --- | --- |
| 前208 | 秦二世二年，赵高权势加重，李斯被杀；反秦战争和地方控制瓦解持续。 | 咸阳作为秦廷政治中心点；不以原秦帝国轮廓覆盖叛乱、失守地区。 |
| 前207 | 子婴继位并诛赵高，刘邦军入武关；秦廷尚以咸阳为中心，关中政局快速变化。 | 咸阳单点；军事进入路线和战场不转为疆界线。 |
| 前206 | 按陕西地方志所用编年，刘邦入关中后子婴迎降，项羽随后入咸阳并焚秦宫，继而三分关中。 | 秦年度图留空中心点；不把秦、汉王、雍王、塞王、翟王混作同一控制主体。汉王南郑中心仍按其独立记录显示。 |

武关地望仅作区域级史事判断，不作为地图点位。参见[《西安市志》秦末年表](https://dfz.shaanxi.gov.cn/zslm/fzzlk/xbsxsxz/xbsxz/xas_16198/201405/P020240923625160882829.pdf)（前207年条目定位于今丹凤县东南）及[全国哲学社会科学工作办公室关于丹凤秦楚古道的考察报道](https://www.nopss.gov.cn/GB/219567/219576/16175133.html)（概述唐以前武关位置有不同观点）。这些资料支持事件区域及地望争议，不支持将某一现代遗址坐标定为刘邦入关的精确点位。

## 纪年校勘与来源

1. [《史记·秦楚之际月表》](https://ctext.org/shiji/qin-chu-zhi-ji-yue-biao/zhs)以汉元年十月记沛公至霸上、子婴降，并依楚汉年序记录诸侯分封。月表纪年与公历年换算须结合秦历、汉历理解。
2. [《史记·项羽本纪》](https://ctext.org/shiji/xiang-yu-ben-ji/zhs)记沛公先入关、子婴降、项羽入咸阳以及三分关中，可用于确认政权转移和年内控制主体变化，不足以复原全年疆界。
3. [《咸阳市秦都区志》·秦末年表](https://dfz.shaanxi.gov.cn/zslm/fzzlk/xbsxsxz/xbsxz/xys_16200/201405/P020240923610537178923.pdf)第534—571行将子婴继位列前207年，将刘邦入关受降和项羽入咸阳列前206年，后接三分关中。地方志采用口径与《史记》月表并列保留。

历史文本的数字化链接用于校勘，不代表获得复制底图或边界的许可。咸阳点使用项目现有近似现代坐标；不表示秦咸阳城垣范围。空间资料的许可、改绘条件和公开展示要求仍需独立审查。

## 运行时和审核边界

- `getHistoricalState(-208…-207)` 显示咸阳 D 级 `control-centers` 点；`getHistoricalState(-206)` 不显示秦中心点，因为史料只支持年内政权末段，无法作为全年位置表达；不新增秦疆域面。
- 前206年西汉建立期另有汉王南郑中心记录；这与秦末咸阳中心是年内政权变化的不同主体，点位不会合并成疆域。
- coverage 决策保留 `leave-unfilled` 且无 `sourceBoundaryIds`；咸阳点不构成已接受的发布疆域资产。
- 本记录为史料核对与地图表现阶段结果，历史、制图、权利及公开地图审核仍须分别完成后，才能将任何疆域面纳入发布。
