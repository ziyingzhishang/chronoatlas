# 后周疆域缺口复核（951—959）

逐年结论数据：[后周 951—959 年](later-zhou-territorial-gap-951-959.json)。

## 逐年结论

| 公历年 | 史料结论 | 地图表达 |
|---|---|---|
| 951 | 后汉中央政权终止，郭威受禅建立后周；刘旻在太原建北汉，北方新政权并存。 | 后周开封中心点；并列北汉太原中心点，不画相邻边界。 |
| 952 | 后周广顺二年，中央政务延续，边防与地方军镇关系仍在变化。 | 开封中心点；缺少可核准的逐年连续疆界。 |
| 953 | 后周中央中心仍在开封；编年所见军事与地方事务不能合并成逐年疆线。 | 开封中心点；疆域面留空。 |
| 954 | 郭威去世、柴荣继位；北汉与契丹军南下，后周在高平战事中取胜。战场、追击和后续地方接管不是一条固定边界。 | 开封中心点；不把高平战线画为疆界。 |
| 955 | 后周对秦州、凤州方向用兵并取得阶段性进展。军事胜利与稳定行政控制需分开。 | 开封中心点；秦凤地理范围不足以据此确定全年多边形。 |
| 956 | 后周南征淮南，战事持续并改变部分州郡的军政控制。 | 开封中心点；不把进军路线或围城范围画为疆界。 |
| 957 | 淮南战事继续，江北城市和州郡的控制转换具有阶段性。 | 开封中心点；不以单一战役结果拼接区域边界。 |
| 958 | 南唐割让江北地、称臣并奉后周正朔。名义秩序变化不等于南唐江南地区改由后周直接管辖。 | 开封中心点；不把奉正朔等同直接疆域。 |
| 959 | 后周向北攻辽取得关南部分地区；柴荣去世、幼主继位，北向军事行动与中央政权转换相接。 | 开封中心点；不以前线或战果拼成全年疆界，也不向960年倒填。 |

## 数据处理

- `gap-zhou_later-951-959` 继续采用 `leave-unfilled`。九个有效公历年均在台账结论中单列，并挂接《资治通鉴》卷290—294。
- 增加951—959年后周开封D级政治中心点；稳定的是中央中心位置，不代表边界稳定。
- 增加951年北汉太原D级中心，标记与后周同年并存的另一政权；两点不表示双方分界线。
- 高平战役、秦凤进兵、淮南战事、南唐割地／奉正朔及959年北征分别作为军事行动、阶段性接收或名义关系，不转绘为直接控制多边形。
- 不自动裁剪共时政权几何，不以959年疆域、最大轮廓或960年后的宋朝范围填补本段。
- 《地理学报》对李晓杰《中国行政区划通史·五代十国卷》的评介确认，附图包括959年后周与北汉政区示意图；现已找到[IKCEST在线图目](https://ikcest-drr.data.ac.cn/map/m2f40)。页面说明该在线图据郭沫若编《中国历史地图集》第二册、比例尺1:1200万。目前只核对图目及元数据，交互图层细节尚未核阅，因此还不能校图或提取几何。该图只可供959年断面州县关系复核，不能替代951—958年的逐年控制证据；来源与公开展示条件待核。
