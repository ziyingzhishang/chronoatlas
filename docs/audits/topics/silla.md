# 新罗前57—377年长缺口专题复核（2026-10-21）

## 结论

- 缺口：前57—377年，共435个民用年（无公元0年）。
- 政权：新罗；现有最大参考 `clio-2590-silla-682` 的来源时段为682—891年，属于统一新罗，不能回填本段。
- 逐年结论：435/435 年均完成核对并明确留空；没有新增边界面，也没有使用最近年份或最大轮廓桥接。
- 表达方式：保持“已研究但无确定疆域资料”的缺口状态，不把王统、朝贡、战争影响或后世统一疆域解释为直接控制国界。

- 57年—79年，脱解尼师今时期：政权名称与王统可核，仍缺少逐年可验证的直接控制边界。

- 248年—297年，沾解至儒礼时期：王统可核，未发现可按年重发布的边界数据；保留空白。
- 298年—355年，基临至讫解时期：4世纪前半的政权整合仍属阶段性过程，不能用后世新罗或统一新罗轮廓回填。
- 356年—377年，奈勿王前期：356年后金氏王统与王权整合增强；377、382年入前秦使反映外交关系变化，不是边界测绘，仍不足以生成年度疆域。
