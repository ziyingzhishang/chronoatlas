# 三国形成期疆域复核：220—223年

状态：逐年史料核对已完成（`source-checked`），结构化结论见 [three-kingdoms-formation-220-223.json](./three-kingdoms-formation-220-223.json)。魏、蜀以都城中心点表达；吴沿用来源提供的同期近似几何。独立历史复核、制图复核、权利与公开展示审核仍待完成。

220年是年内政权交替：东汉来源轮廓不能证明全年直接控制，也不能转作曹魏疆域。新增 `conflict:han-wei-transition:220`，仅在220年运行帧暂扣215—220年低置信度轮廓；219年仍显示来源原面，原始几何保留、不裁切、不转交。220年仍只显示曹魏洛阳D级中心点，疆域面留空。

## 数据变更

- 增加曹魏洛阳都城中心参照点，覆盖220—223年。
- 针对220年汉魏年内交替，新增 `conflict:han-wei-transition:220`，只在220年暂扣东汉低置信度区间轮廓；219年正常显示，原始来源几何保留且不裁切、不转交。
- 增加蜀汉成都都城中心参照点，覆盖221—223年。
- 将吴政权实体起年调整为221年，补入孙权迁都武昌的逐年结论和低置信度D级中心点；独立改元仍从222年记录，221年不显示吴的来源疆域面。
- 两条均为 D 级 `control-centers` 点位，不是疆域面；相应的220—223年、221—223年旧缺口仍保留为“疆域边界留空”。
- 吴既有来源记录 `clio-1312-wu_three-222` 从222年起显示，原始几何、222—237年来源时段和 Cliopatria v0.2.1 CC BY 4.0 署名条件均保留。本轮未裁切该几何。逐断面检查发现魏洛阳、蜀成都两个 D 级中心点均不落入吴来源多边形；魏、蜀也没有面状疆界，因此当前图形之间没有可判定的政权面重叠。这个几何检查只说明地图没有互相压盖，不校定历史边界或接壤线。
- 新增223年“刘备卒于永安宫”事件。史籍支持卒地为永安，重庆考古空间研究将永安宫城讨论在奉节宝塔坪一带；对精确宫址的认定仍有争议。地图仅加低置信度区域参照事件点，不表示宫殿建筑、遗址边界或蜀汉疆界。点位依据高德宝塔坪遗址POI经GCJ-02转WGS84作近似定位；来源权利及公开地图展示条件待审核。
- 新增 Herrmann 与 Westermann 1935年《Historical and Commercial Atlas of China》三国概览图作为权利状态较清楚的宽时段交叉参考。图题涵盖220—265/280年，无法单独确定220—223年的逐年控制边界；未从图中提取魏、蜀几何，也未复制地图图像。Commons页面标注Public Domain Mark 1.0，项目公开展示仍须按来源版本和适用地区另行核验。
- 相关魏、蜀 coverage 条目已分别链接逐年结论与史料 ID，继续将疆域面留空；不会因地图点位或吴的范围面而自动生成边界。
