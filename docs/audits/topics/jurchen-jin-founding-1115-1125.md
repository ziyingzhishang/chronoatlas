# 金（女真）建国与扩张期疆域复核（1115—1125）

## 结论

1115—1125 年金朝处于建国、攻辽和持续扩张阶段。地图逐年显示会宁府（上京）作为金早期政治中心的 D 级参照点；这不是边界几何。辽的州县归附、反复争夺、宋金议地、辽亡及随后攻宋等过程改变了区域控制状态，不能用一个固定轮廓覆盖整个区间。

本段台账的疆界几何仍留空。历史中心依据与空间边界证据分开记录：会宁府点只表示政权中央政治中心，现代坐标为阿城区白城遗址一带的近似定位，不表示金上京城墙范围或金朝直接控制范围。

## 记录与审核边界

- 历史来源审核：已按《金史》卷2、卷3逐年核对建国、辽金战事、州县归附、外交分地和辽亡节点；来源用途与疆界证据边界已登记在机器可读台账。
- 逐年数据：`jurchen-jin-founding-1115-1125.json`，覆盖 1115—1125 全部 11 个公历年，不含公元 0 年。
- 地图记录：`special-jurchen-jin-1115-1125-huining-center`，`evidenceLevel: D`、`derivation: control-centers`；点位逐年有效，所有年份的 `territoryBoundary` 均为空。
- 台账 `gap-jin_jurchen-1115-1125` 维持 `leave-unfilled`，`sourceBoundaryIds` 为空；这表示没有疆界几何，不妨碍显示有依据的中心点。
- 历史审核：以《金史》卷二太祖纪和卷三太宗纪按年核对金建国、辽金战争、州县归附、燕京接管、宋金外交和1125年辽亡。金上京政治中心阶段由项目资本史时段资料记录为1115—1153年。
- 制图审核：仅绘中心参照点，不绘攻取州县、战场、宋金条约线、臣属关系或年内军事路线；不自动裁剪并存政权几何。
- 来源使用权：只登记史籍与项目既有会宁府现代近似坐标，不复制史籍页面地图或历史边界数据；公开展示条件仍需按底图和地图发布规则另核。
