# 隋朝建立期疆域复核（581—586）

逐年结论数据：[隋建政与迁都初期 581—586 年](sui-founding-581-586.json)。

## 结论

这六年均不绘制疆域面或确定边界。地图以两个有年代范围的 D 级参照点表达都城中心：581—582 年长安；583—586 年迁都后的大兴城（今西安区域）。两点沿用现有 `changan` 现代近似坐标，只表达政权政治中心，不表示古城垣范围。

隋在 581 年受禅建立；《资治通鉴》卷一七五同年记其命代太子镇洛阳，同时继续记载陈朝政务，显示隋陈并存。隋文帝开皇二年（582）开始营建大兴新都，开皇三年（583）迁入。西安市地方志办公室的遗址说明记载了营建和迁都时序，并称考古勘探基本摸清都城格局和范围；本次未复制其城垣数据。隋灭陈统一南方在 589 年，不可倒推为本段疆界。
