# 楚终结年疆域审计：前223年

- 台账：`gap-chu_warring--223--223`（史事来源互校；控制中心与疆界均留空）
- 年度记录：[`chu-warring-termination-223.json`](./chu-warring-termination-223.json)
- 年份：前223年，秦始皇二十四年
- 史事：《史记·楚世家》《六国年表》及《资治通鉴》将负刍被俘、楚亡记于前223年。《史记·秦始皇本纪》另在前224年记未具名“荆王”被俘，随后记昌平君在淮南反秦。雷虹霁、陶然（2019）提出这可能是连续战事中的不同事件，并推测寿春在前224年已为秦军占领；该解释可用于校正中心点判断，仍作为学术假说记录。
- 地图表达：前223年不放置楚方控制中心点，也不绘制楚或秦的全年疆域面。若采上述解释，寿春不再作为该年楚方中心；这不等于已知秦军在全年的完整控制范围。
- 空间证据缺口：未具名“荆王”与负刍的王位承接关系、寿春占领时序仍需更多材料复核。雷、陶的论证支持“至迟前223年寿春可能已归秦军控制”，但不能确定周围县邑接收时间、楚方残余抵抗范围或连续边界；疆域多边形和来源边界 ID 继续为空。
- 来源：[《史记·楚世家》卷四十](https://zh.wikisource.org/zh-hans/史記/卷040)、[《史记·秦始皇本纪》卷六](https://zh.wikisource.org/zh-hans/史記/卷006)、[《资治通鉴》卷七·秦纪二](https://zh.wikisource.org/wiki/資治通鑑/卷007)、雷虹霁、陶然《王翦灭楚战争新探》（原刊《宝鸡文理学院学报（社会科学版）》2019年第5期；[原文转载](https://www.baojinews.com.cn/2/2twlm/xxptsy/570861.shtml)）。论文提出的寿春占领时间只作为研究解释，不复制图件。寿春都城阶段与坐标仍见项目[资本史资料](../../../src/data/capital-history.ts)和[地点资料](../../../src/data/places.ts)，但不用于本年楚方控制判断。
- 审核：对照《秦始皇本纪》秦王政二十三年、二十四年与《楚世家》负刍四年、五年，以及《资治通鉴》始皇帝二十三年、二十四年；将前224、前223年记载保留为可能连续的不同事件，不据此声称存在同一事件的年代矛盾。中心位置与边界表达分别记录。来源使用权与公开展示条件仍需按项目发布流程单独核验。
