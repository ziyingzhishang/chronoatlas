# 唐朝建立期疆域复核（618—622）

逐年结论数据：[唐初 618—622 年](tang-founding-618-622.json)。

## 结论

618—622 年疆域几何继续留空；地图逐年显示唐中央政治中心长安的 D 级控制中心点。唐初处于多政权并立和统一战争中，年度控制范围变化显著；本轮没有可直接关联、许可状态清楚且可逐年复核的唐初边界几何，因此不以长安点、后期唐疆域或通用历史地图替代边界。

《资治通鉴》卷一八五至一九〇记载唐在长安建立中央政权，并在 618—622 年持续记载周边势力和军事行动。卷一九〇武德五年（622）开篇记刘黑闼自称汉东王、定都洺州及唐军继续交战，表明本段末年统一战争仍在继续。地图在保留唐长安中心的同时，增加洺州州治区域事件点，标明并存对手的政治中心；不表示唐控制该地、汉东王的势力范围或洺州城墙。CHGIS 点位用于区域定位，许可为 CC BY-NC 4.0，公开展示权另行核验。

复核运行时状态后，发现原标题只列唐与吐蕃，漏掉当前数据已记录的高句丽、新罗、吐谷浑、突厥；同一史料还逐年记有薛举／薛仁杲、李轨、王世充、刘武周、宋金刚、窦建德、刘黑闼等唐初对手。现按年度标题补充提示这些并存关系和重要战事。标题不代表上述唐初对手都已建成独立政权实体或有疆域几何；这是本段发现的台账外建模缺口，登记待后续按逐年来源复核政权记录、中心点和疆域表达。没有新史料支持的控制边界仍留空。
