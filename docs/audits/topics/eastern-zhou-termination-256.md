# 东周王室终止节点复核（前256）

## 结论

- 台账：`gap-zhou_eastern--256--256`（终止事件与纪年来源已核对；疆域继续留空）。

前256年按《史记·周本纪》和《资治通鉴》卷五的传统纪年，记录周赧王及周王室终局。该结论不等同于所有东周政治实体在此前256年一并消失：东周君国另有前249年终止节点。本年地图只保留洛阳城市级都城参照点，不绘周王畿疆域面。

年度机器可读结论见[前256年审计台账](./eastern-zhou-termination-256.json)。台账明确记载地图表达、来源、前255/前256纪年异说和独立的王畿边界 `evidenceGap`。

## 史料与范围判定

- 《史记》卷四《周本纪》记周赧王五十九年秦攻西周、周君降秦、周民迁往惮狐，以及九鼎入秦；该叙事用于王室终局的传统纪年，不提供逐年王畿边界或君王最后驻地的精确城市坐标。[《周本纪》](https://zh.wikisource.org/wiki/史記/卷004)
- 《资治通鉴》卷五按前256年记周赧王终局；卷六继续叙述秦庄襄王元年（前249年）东周君与秦的冲突及东周国终止。因此，周王室终局与东周君国终局分列，不把前249年的事件提前到本条。[卷五](https://zh.wikisource.org/zh-hans/資治通鑑/卷005)；[卷六](https://zh.wikisource.org/zh-hans/資治通鑑/卷006)
- Early China 关于秦史新出金文的研究讨论西周兼并节点的前255/前256纪年差异。项目沿用现有覆盖台账和《资治通鉴》的前256年口径，并在年度结论中保留异说；年表选择不构成边界证据。[研究论文](https://www.cambridge.org/core/journals/early-china/article/question-of-interpretation-qin-history-in-light-of-new-epigraphic-sources/84FA98350F7FA181CEEBE3E6157999AA)

周赧王后期迁居西周，东西周分治及秦军接收过程无法由当前来源恢复为前256年全年稳定的王室直辖边界。现代洛阳城市点仅表示既有都城中心参照，不代表宫城、城墙或王畿界线。秦当年已有疆域数据不因周王室终止结论而裁剪；东周王室与东周君国也不据此合并为一个多边形。
