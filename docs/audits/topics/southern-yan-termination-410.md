# 南燕终止年疆域与广固中心核查（410）

《资治通鉴》卷115记410年正月慕容超登广固城、二月刘裕攻破广固，慕容超突围被获并送建康。由此可以把广固作为南燕覆亡前的年内终局中心作点状表达；点不代表南燕全年独立控制、围城期间的边界或东晋随后稳定接收区域。

本项地图表达为D级 `control-centers` 点，疆域面留空。来源版本为维基文库《资治通鉴》卷115数字文本；本项不复制地图或图像。公开展示前仍须另行核对数据许可和地图发布条件。

## 审核状态

- 历史来源审核：已核对《资治通鉴》卷115及《晋书》卷128的覆亡时序；来源用途与不可推导的空间范围已写入机器可读台账。
- 制图审核：广固仅作D级终局中心参照，无南燕疆域面，不将攻守过程绘为边界。
