# 第110轮首都链路任务 C 审计

## 范围

本轮专门核验 7 个剩余跨政权、共享或重复候选：秦—楚汉之争、唐—洛阳行幸、后梁五代转折、后周开封遗产、东周东迁、后凉姑臧遗产、北宋建政重复节点。

安全闭合最多 1 项，且必须同时满足：

1. 首都阶段明确提供目标政权、地点和有效年代；
2. 事件或遗产拥有独立、可单独导航的端点；
3. 端点明确支持目标政权，不只是同城、后世承接或共享城市层；
4. 事件年份或遗产阶段与目标首都阶段重合；
5. 语义不重复现有建政事件，也不把跨政权遗产拆成单一政权事实。

## 结论

本轮没有达到安全闭合条件的候选，因此不修改任何政权详情的 `eventIds` 或 `heritageIds`，不新增事件或遗产实体。7 项均已固化为可执行分类审计，后续只在阻断证据被补齐后重新评估。

## 固化的执行规则

- 共享事件必须保留多政权归属，不能因地点与首都阶段重合而归入单一政权。
- 重复建政节点必须保留规范事件链，不能通过再次写入 `eventIds` 制造重复叙事。
- 跨政权或跨阶段遗产必须按考古层和政权阶段拆分；同城不等于同一遗产归属。
- 每项都必须先取得对应的独立端点、来源、时间重合和语义差异，再进入下一轮闭合候选。
