# 第112轮任务 A：秦楚汉与汉代剩余候选边界审计

本轮只复核秦—楚汉之争事件、长乐宫、茂陵、杜陵和白马寺。闭合上限为一项；闭合条件是政权、地点、年代、来源和独立事件端点同时一致。对遗产而言，独立事件端点还必须能够说明该遗产本身的营建、建置或明确形成阶段，不能只证明同城、同政权或同一历史背景。

## 核验结果

| 候选 | 已有证据 | 本轮结论 |
| --- | --- | --- |
| 秦—楚汉之争 `chu-han-contention` | 事件同时归属 `qin` 与 `han_western`，地点含咸阳，阶段跨前206年至前202年；咸阳只是秦亡、分封和战争背景的一部分 | 不并入秦首都事件链。不得把共享转折节点改写为秦专属事件 |
| 长乐宫 `changle-palace-site` | 遗产详情同时归属 `han_western` 与 `xin`；现有关联事件不是长乐宫专属端点。`han-changan-new-city` 只证明长安新城营建，未证明长乐宫营建 | 不并入西汉政权详情。跨政权且缺少宫殿专属端点 |
| 茂陵 `maoling` | 单列西汉、地点长安、起点前139年；仅关联 `han-imperial-accession`，该事件为前202年氾水之阳即位背景 | 不并入西汉。不得把陵墓年代或即位背景事件当作茂陵营建事件 |
| 杜陵 `du-ling` | 单列西汉、地点长安、起点前74年；仅关联 `han-imperial-accession`，地点和年代均不匹配杜陵营建 | 不并入西汉。不得把陵墓年代或即位背景事件当作杜陵营建事件 |
| 白马寺 `white-horse-temple` | 详情同时归属 `han_eastern` 与 `tang`；公元68年是创建传统，今日建筑为历代重建、修缮与保护叠合；没有独立建筑端点 | 不并入东汉。跨政权且现存建筑层未形成可归属东汉的独立端点 |

## 结论

本轮闭合 0 项。现有证据没有一项满足独立端点条件，因此不修改秦、汉政权详情，也不新增事件或遗产事实关联。

新增边界测试 `capital-reference-round112-han.test.ts` 固定以下不可越过的边界：

- `chu-han-contention` 可作为秦亡至汉初秩序转折的共享学习入口，但不能进入秦首都专属事件链。
- `han-changan-new-city` 的城市营建证据不能升级为长乐宫宫殿营建证据。
- `han-imperial-accession` 不能替代茂陵、杜陵各自的营建事件。
- 白马寺的创建传统不能替代今日建筑群的东汉原构或单一朝代建筑端点。
