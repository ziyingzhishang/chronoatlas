# 全局语言一致性验收

日期：2026-10-20

## 范围

- 语言：大陆简体、香港繁体、台湾繁体、英文。
- 界面：地图标签、政权与地点目录、政权详情、事件出处、时间轴和底图署名。
- 数据约束：不改动几何、稳定 ID、年代、来源 URL 和原始值。

## 实现结果

- 政权名称由结构化解析器产生，地图使用紧凑标签，目录与详情使用完整名称。
- 未核验世界名称在三种中文中显示“原名：…（中文译名待核验）”，地图缩写为“…〔译名待核验〕”；英文保留来源原名。
- 来源标注、所属关系、文献原题和地图署名保留原值，并使用当前语言的前缀标明。
- 新增语言纯度审计：普通 UI 和已核验实体不得无标识混入其他文字；仅结构化原文、署名和语言名称可豁免。
- 切换语言仅更新展示数据，不重建 MapLibre 实例，不触发镜头移动，不更改所选年份。

## 独立代码审查

审查发现的高优先级问题均已修复：

- 英文未核验世界实体不再显示“中文译名待核验”流程提示。
- 展开时间轴的朝代色带使用当前语言。
- 政权审计改为读取 `LocalizedNameMeta.status`，不由测试随意将普通实体标为原文豁免。
- 语言切换回归增加了选中政权、卫星底图与图层开关状态保持断言。
- 英文别名、事件摘要和坐标改用英文标点。

## 合法保留原文

- 来源机构、数据集、许可证、作者和文献原题。
- Esri、Natural Earth、Cliopatria、CC BY 4.0 等署名与专名。
- 暂无经核验中文译名的世界实体，必须同时显示“译名待核验”。

## 限制

- 地图瓦片是远程栅格，自动化审计不检查影像内文字。
- 语言纯度审计是测试工具，不会在运行时自动翻译或改写史料。
