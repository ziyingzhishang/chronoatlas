# 全历史时间轴与疆域资料验证

## 结果

- `npm test -- --run`：13个测试文件、41项测试通过。
- `npm run build`：TypeScript与Vite生产构建通过；仍有主包超过500KB的体积警告（gzip约484KB），未掩盖或关闭警告。
- 数据：24个资料年份、51个图形、14,122个原始坐标点；生成JSON约512KB。
- 独立只读审查检查了10,026个可导航年份，并确认51个导入几何与缓存来源一致、文件摘要与清单一致。

## 本地浏览器实测

- 默认800年地形图：唐、吐蕃、南诏原始轮廓显示；新罗缺口明确标注。
- 《资治通鉴》快捷范围：滑块索引7597—8958，对应前403—959年。
- 逐年视窗：有年度小刻度和两年主刻度；前1年点击下一年变为公元1年，无0年。
- 年份输入仅在提交后跳转，0年有明确校验提示（组件测试覆盖）。
- 799年与800年资料明确区分；关闭/打开邻近断面可清除/恢复图层，所选年份不变。
- 1100年宋辽夏资料：可选择北宋并显示1100年、原始名称、213个坐标点和源文件链接。
- 明朝下拉选择会聚焦1368—1644年；1500年断面、卫星图及30°旋转均正常。
- 1500→1501年切换保持地图缩放2.8、方位30°，未复位相机。
- 前221年显示缺少疆域资料，没有旧版通用多边形。
- 2026年显示中华人民共和国目录和疆域待补；没有把历史轮廓当作现代边界。
- 本轮浏览器开发日志未发现错误。
- 未进行真实手机触屏测试；交互引擎沿用上一轮配置。

## 独立审查修复

1. 武周时期的唐色带与本年政权目录不一致：新增实际在位分段，700年只显示武周；705年仍允许年度过渡重叠。已先写失败测试、再修复并在浏览器复核。
2. 视窗移开后重新提交相同年份未居中：提交时显式处理视窗，测试与浏览器都验证800年能够回到视窗内。

## 有意保留的数据限制

这是可追溯断面的阅读原型，不是全历史逐年精确地图。先秦、秦、三国、五代多数政权、近现代及大量并立政权仍缺疆域；扩展时期的地名尚未补全。原始矢量是大陆尺度低置信度参考，不能把顶点变多、海岸更细当作史实已校准。

CHGIS V6不能直接再分发，Hartwell并非精确古界，人口研究范围也不是完整疆域。更高精度需要授权合适的资料及逐时期校勘；不会继续用程序生成的轮廓掩盖缺口。
